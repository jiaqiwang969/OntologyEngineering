开发验证实际包括：179 个受影响库案例、58 个 CLI 案例、3 个新安装/派发单元案例、memory 的 107 个常规案例及另行执行的大原件案例。六个受影响 crate 的全部目标编译检查通过。统一安装后另跑原生接收测试，1 passed；公开 memory 示例 14 次调用全部成功。

六模块补充迁移后，四份 diff 对固定上游实际应用并逐文件核摘要；两份完整本地 Skill 保留现用规则。共享接续脚本 36 项测试、REA 启动配置 9 项测试通过，包括祖先软链接、空/相对 JDK 路径和启动后记录失败的拒绝/清退反例。测试调用当前安装的真实 Rust 核验，并使用受控子进程检查预算与清退；这些结果不代替新宿主的 MCP 连接或 Ghidra、采集器实际运行。

完整 Project 的工具回流使用新冻结的对象与条件，再实际调用 Jacobian 并独立精确代回。23 次调用符合预期，包含版本不符、来源篡改和条件变化的 3 次明确拒绝。数学决定为有范围的 supported，adopted=false；离散采样不能证明连续覆盖的未知仍保留。反馈为真实 `no_delta`，没有宣称经验导致性能或工程收益。复现入口见[完整案例](FIRST-PROJECT.md)。

锁定真实 ggen 执行生成后，再重新生成比对：`consistent`，`drift=[]`，来源和组合均 matched。编译来源摘要为 `a34d5a5731c4b5e515ea83f4fde9cc39b999bc299347585bf80fdb671fc7ee49`。这不代表完整 Semantica、所有 CAD 平台或历史工程资格已验收。

部分型别和页面回归实际使用私有固定原件；原件不随仓库发布，接入方式见[使用说明](USAGE.md)。公开新用户案例不借用这些原件。隐私扫描的 52 项命中保留原始 blocked 结果；逐字节复核确认是检测字符串、合成测试/编码与二进制夹具、公开示例和占位路径，没有据此删除负例或放宽扫描规则。私人 session、项目、来源和本机配置均排除在公开树之外。

独立目录预检使用已发布 `615009e9`，实际重新构建并核八程序身份、空记忆库、14 次公开记忆调用和原生接收。GitContribute、LeanToken、Jacobian 与 SmokingGun 的限定案例通过，SmokingGun 的部分 TypeScript 覆盖仍保留。REA 返回静态结果但进程清理检查被当次沙箱拒绝，记录 `cleanup_incomplete`；Flameox 的系统信息查询被拒绝，记录 `DECODE_FAILURE`。完整新工具 Project 回流在预检中未完成。该预检早于完整六模块差异与电子模块补充；它不是整棵旧 skills 备份后的最终验收。
