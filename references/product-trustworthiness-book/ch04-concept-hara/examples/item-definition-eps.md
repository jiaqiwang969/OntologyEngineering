# 相关项定义：电动助力转向 EPS

状态：合成教学草稿。结构依据 ISO 26262-3:2018 Clause 5，内容不代表任何具体车型或供应商设计。

## 1. 相关项需求清单（5.4.1）

| 5.4.1 要素 | EPS 教学内容 | 证据状态 |
|---|---|---|
| 法规、国家/国际标准 | 待项目识别目标市场转向系统、EMC、电气安全及整车准入要求 | 待补 |
| 整车层功能与模式 | 根据方向盘转矩和车速提供电动助力；正常、降级、关断/失效模式 | 教学定义 |
| 质量、性能、可用性 | 助力范围、响应时间、转矩精度、可用性和降级能力均为项目 TBD | 待补 |
| 功能依赖与环境 | 依赖整车供电、车速信号、通信网络和机械转向链；温度/电压/振动边界 TBD | 待补 |
| 已知行为短板、故障模式和危害 | 非预期助力、助力丧失、错误方向助力、振荡等作为 HARA 候选 | 教学清单 |
| 执行器能力 | 电机峰值/持续转矩、上升时间、转矩梯度和机械传动比均为项目 TBD | 待补 |

## 2. 边界、接口与交互（5.4.2）

| 项 | 教学边界 |
|---|---|
| 相关项内元素 | 转矩/角度传感器、EPS ECU、功率级、助力电机、减速机构 |
| 输入接口 | 驾驶员转矩、方向盘角度、车速、点火/电源状态、整车模式 |
| 输出接口 | 助力转矩、诊断状态、降级/告警请求 |
| 外部依赖 | 低压电源、通信网络、机械转向柱、轮胎/悬架/车辆动力学 |
| 对整车的影响假设 | 助力转矩经机械链改变转向轮角与车辆横向运动 |
| 其他系统需要的 EPS 功能 | 驾驶员辅助和自动驾驶功能可能请求转向控制或读取状态 |
| EPS 需要的外部功能 | 可信车速、整车模式、电源质量和独立告警通道 |
| 功能分配 | 感知/控制/执行/诊断的具体元素分配在系统设计阶段确定 |

## 3. 运行场景与模式

高速公路高速行驶、城市中低速、低速泊车、坡道、湿滑/低附着、起动和关断过渡均需进入场景库。场景粒度不能被人为切得过细，从而通过降低单个场景暴露概率不恰当地降低 ASIL（3-6.4.2.7）。

## 4. 当前假设

| 假设 ID | 陈述 | 后续验证 |
|---|---|---|
| `Assumption_MechanicalPathAvailable` | 助力丧失后机械转向链仍可传递驾驶员转矩 | 集成相关项试验/分析 |
| `Assumption_TargetMarket_Highway` | 目标市场的高速运行暴露足以支持 E4 | 市场与使用剖面数据 |
| `Assumption_AverageDriver` | 可控性以标准假定的正常驾驶员状态评估 | 驾驶员研究/专家论证 |
| `Assumption_UnintendedTorqueProfile` | 给定非预期转矩幅值和上升时间足以造成 C3 | 车辆动力学和试验 |

这些假设按 3-6.4.4.4 建模为独立实体，并保持待验证状态。

## 5. 未决证据
