# 公共发布状态

当前状态：**BLOCKED — 不应把本地工作树整体打包或继续发布为已清权利的开源版本。**

本文件记录发布门禁，不否定现有两卷的教学价值，也不构成法律意见。

## 当前阻断项

- 项目尚未确定根级代码、文字、图像和 PDF 的许可方式；公开可见不等于已授予开源许可；
- 第二卷部分来源审计仍登记为 `pending`、`review_required` 或
  `not-cleared-for-republication`；
- 前言含作者提供的真实商业接触缘起；公开前需要作者明确批准，或改成不指向真实事件的
  合成叙事并同步重建 PDF；
- 部分表格、术语卡和方法题库属于高密度标准派生表达，需要独立权利审查；
- 书籍 PDF、图片及其他二进制资产仍需做元数据白名单检查；
- 公共资产尚未形成逐项 rights/privacy/release manifest。

## 已完成的隐私改进

- 公共候选文本和脚本不再硬编码个人绝对路径；
- 新增默认拒绝、白名单发布政策；
- 新增公开前隐私扫描器，并支持扫描 ignored 工作树文件；
- 新书脚手架默认隔离原始标准、企业证据、会话、密钥和未清权利图；
- `standard-to-book` Skill 明确禁止把自动门禁升级成认证、合规或发布授权。

## 解除阻断所需决定

1. 作者批准或合成化处理真实缘起叙事；
2. 对每个标准派生制品完成权利裁决；
3. 选择并登记代码、文字、图像和 PDF 的许可方式；
4. 建立公共资产 manifest，并使所有放行资产状态为明确批准；
5. 清理 PDF/图像元数据，从干净提交使用 `git archive` 或等价白名单导出；
6. 运行隐私、秘密、权利、技术和读者门禁，再由有权人批准发布。

在这些项目完成之前，可以继续本地开发、使用合成示例和评审方法；不得声称当前包已经
完成隐私、版权或正式出版放行。
