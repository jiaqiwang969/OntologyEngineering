\chapter{前言}

这本手册是《工程本体论》的成书版本。它不是第二套代码仓库，
而是一份\textbf{带着读者走}的可执行规格导读：每章先用日常语言把概念讲清楚，
再用 Semantica built-in package 中的受控资产节选印证讲解，最后明确 package、
scenario、oracle、能力边界与 release status。理论与方法留在书里；所有机器可执行
语义只在 Semantica 中维护。

\begin{noteblock}
\textbf{材料与状态说明}：第 2、4、5、6、9 章教学材料提取自原书稿；
第 1、3、7、8 章按全书脉络补写。迁移不抹去来源差异：Semantica manifest 用
\texttt{source\_anchor}、哈希、derivation、payload status 与 gap 明示原文、提取、
适配和缺口。书中说“已迁入”不等于 runtime 已支持，“scenario pass”也不等于发布完成。
\end{noteblock}

\section*{如何阅读本手册}

\textbf{正文以讲解为主，包资产以节选为辅。}
书中出现的语义片段由构建脚本依据迁移账，从 Semantica 的 allowlisted package
按 asset id 读取并校验；片段下方只标唯一 package/asset，历史来源与 derivation
留在 manifest 中查证。迁移前路径不是运行入口，
Protégé、Jena、owlready2 或 pySHACL 的单独运行结果也不是本书的发布证据。

\textbf{复算以同一 runner 为准。}
Python、CLI 与 MCP 都委托 \texttt{SemanticPackageRunner}。执行时先查看 manifest，
再运行具名 scenario，最后单独执行 release verification；未知包、未知场景、缺失资产、
哈希不符或不支持的 DL/SWRL/时态/概率能力均应 fail closed。

\textbf{代码框的排版约定}：注释以\textcolor{cmtgray}{灰蓝色}显示，代码为黑色；
描述逻辑符号（\(\sqsubseteq\)、\(\sqcap\)、\(\forall\)、\(\exists\) 等）以标准数学记号排印。

\textbf{关于插图}：各章章首插图由图像模型 \texttt{gpt-image-2} 生成，为概念示意图。
每幅图下方保留了实际使用的完整提示词，既说明图的来源，也便于复现或替换。
全部提示词统一维护在 handbook 目录的 \texttt{gen\_figures.py} 中，
书中展示与实际生成完全一致（单一来源）。
