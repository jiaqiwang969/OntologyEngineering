# 工程本体与制造协作 0.5.8

本版让 CAD、制造工艺与成本模块共用工程证据方法，并接入 Jev 批量初判。员工可以持续提供群聊、图纸和现场反馈，由助手维护私有项目本体，追踪问题和依据，修订方案；员工无需填写本体或 JSON。客户资料、实际参数、报价和项目本体不随 skill 分发。

## 相比 0.5.7

- **判断前先看证据能证明什么。** 共用方法检查测量口径、模型适用范围、因果对照、验证独立性、推导条件和成本依据，避免把模型算完当成实物可行。
- **大量资料先做候选整理。** Jev 处理带来源和对象版本的有界问题；不确定、冲突和关键判断进入复核。同一段话可同时含需求、建议与假设，不强行归成一个事实。
- **变更沿依赖传递。** 原始资料、接口、工艺或版本变化时，重新检查受影响的 CAD 主张、路线、检验、报价及交期。事实采用和可复用方法晋升仍经 Semantica 原生审查。
- **升级可以追踪和回退。** 锁定模型、问题、合同、适配器和 Semantica 组件；记录批次、失败与重放，支持模式迁移和兼容性核对，不自动把旧结果当成新模型的结果。
- **持续跟进工厂讨论。** 新增制造协作入口及可选现场任务卡，把现场反馈接回方案。私有项目本体与通用方法分别维护。
- **方便试用。** 普通完整包包含两卷书、CAD/工艺模块与运行组件；另提供所有者明确授权、附带共享临时 Jev 凭据的完整体验包。实验凭据可撤销，自己的密钥优先。

本次也修复 JSON 非有限数值导致批次中断、服务失败原因不清和 Jev 凭据识别遗漏；异常记录保留失败状态，其余记录可继续。制造冻结案例 `0.1.1`、工程证据包 `0.1.0`、判断接入包 `0.2.2`、Jev 适配器 `1.1.0` 与 Semantica `0.6.5+oe.6` 分别记录版本。

## 验证范围

可执行验证与归档摘要随 Release 的验证记录提供。开发验证覆盖合成输入、来源绑定、错误隔离、批次恢复、语义原生审查、文件闭包和隐私检查；不等于真实生产验收。

独立模型质量、双模型升级对照、跨项目泛化及真实总成本评测按用户决定留待后续项目实践，未标为通过。前版已有的书源与 Semantica wheel 绑定检查仍有 **46/238** 项未通过；本次没有改动书源或绕过该门禁，也不宣称两卷书的语义发布验证全部完成。
