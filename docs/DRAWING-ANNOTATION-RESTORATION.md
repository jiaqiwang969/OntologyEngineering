# 注记位置观察与恢复

显式 display intent/4 与 params/4 复用原 /3 准备一次、只读观察 /7 的路径。原 /1–3、原文件/副本、单位、几何父引用、尺寸值、完整文字框签名、显示清单及 WCS 恢复判据保持。

附注写入可能改变布局。Rust owner 在首改前读取同一 alive、自有平行尺寸的 AnnotationOrigin、IsOriginCentered、HasAssociativeOrigin，再记录加注后、导出后、撤注后与最终观察。注记原点不能从文字框原点反推；原点关联和尺寸几何父关联分别核查。本有界实现遇到关联原点或未知先拒绝，未实现关联原点恢复；这不取消原完整工程范围。

撤注后重新核身份与实际状态，仅变化时恢复。居中变化可能影响原点，故先恢复居中，再重申捕获原点；无变化则无 setter。单对象查询或恢复失败保留记录，其他清理继续。全部原清单及新状态必须精确恢复，不能强制刷新、重入上下文、忽略字段或加容差取得通过。

来源是当前安装 NX SDK 的 Annotations_Annotation.hxx 与 Annotations_Dimension.hxx 公共 API；窄 C++ ABI 仅调用原生接口，身份、前提、状态比较及结果审查由 Rust 承担。规范在原 nx-sheet-dimensions 片段，真实 ggen 生成共享状态。Windows SDK 与 include 闭包、两平台软件、真实 NX、独立 PDF 解析及图面分别接收，实际状态见维护回执。

原生第一分支恢复全部通过后，才开展仍未完成的非 WCS 坐标系显示比较。图面可读不能代替尺寸/基准/配合/材料/载荷/制造/检验或最终实物计量；完整 63 项目标、CAD16 和 Semantica 范围不变。开发回放不证明 RRSI 方法收益。
