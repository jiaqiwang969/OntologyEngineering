# AutoCAD MCP 已退役；图纸检查方法保留

`autocad_call.py` 与 `autocad_service.sh` 已删除旧传输和服务控制实现，
所有参数与环境设置均返回退出码 64。它们不能再连接、启动或重启 AutoCAD 服务。
本页不提供旧服务部署或重新启用路径。当前 CAD 使用
[NXOpen／Journal 直连](nx-execution.md)，工具对具体 DWG／DXF 版本的支持须按实际输入核实。

下列图纸检查经验继续适用于有授权、可验证的读图工具：

- 先确认文件身份、版本、单位、活动图纸、模型空间和布局；多文档场景须明确对象，
  不把当前活动文档当作用户指定文件。
- 检查图层、实体类型、块引用、文字、尺寸和标注样式；保留实体标识及来源文件，
  使检查结果可回查。图形外观不替代尺寸和坐标核验。
- 查看原件，修改工作副本；另存后核对输出路径与文件身份，避免覆盖用户原图。
- 导出 PDF 时明确布局、纸张、比例和打印范围；导出 DXF 时记录文件版本。
  重新读取产物，核对几何、单位、文字和标注是否保留，不能仅凭成功返回判定完整。
- 截图可能受窗口遮挡、最小化或刷新状态影响；使用截图前核对对象、视图和时间，
  不把陈旧画面当成当前原生模型证据。命令或对话框未完成时先查明状态，不反复派发修改。

旧工作站上的软件版本、服务端口、COM 中继和命令实测记录是历史环境观察，
不构成当前能力或执行授权。当前任务仍需取得适用的原生回读与文件核验证据。
