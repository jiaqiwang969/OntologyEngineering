# 尺寸引用辨识与原生 PDF

`export_identified_drawing_pdf` / `oev2.nx-drawing-identified-pdf-params/1`
在现有 PDF 输出、图页、尺寸父引用和完整清单 owner 上接续。原
`export_drawing_pdf` /1 的含义与检查保持不变。

新意图的 `base` 保留来源、图页及清单；`references` 把每个原独立尺寸意图
对应到 `upper` 或 `lower`。适用范围限定为单体 mm 零件的绝对 Z 上下界圆心。
Rust 按当前几何与关联唯一匹配完整尺寸集合，再由其模型 Z 值生成说明；
不接收任意自由文本作为几何事实，不改变数值、父对象、单位或原容差。

原生 SDK 在内存副本内读取完整附加文本数量，仅接受原先为空的文本，设置并
回读 BelowText，再读取、隐藏 WCS，调用原 PrintPDFBuilder。
无论局部成功或失败，都尝试恢复每个尺寸的原空文本及原 WCS 可见状态。
成功还要求完整关联、几何、原清单恢复，输入与副本文件字节不变；不调用保存。
CAD 文件中的持久注记不是这个动作的交付范围。

`cad drawing receive-pdf` 按显式新动作使用 `/2` 接收报告，复核完整任务、
程序、输入输出与原生记录。新动作的正式使用需要当前 Mac/Rust 与 Windows/SDK
接收。PDF 解析、文字与图面检查由独立消费者执行；WCS getter 成功不能证明
实际打印的三轴已消失，附注存在不能证明布局清楚。

说明区分名义模型的圆心引用，不构成几何公差、制造基准或实物合格声明。
教材中要素与要求的区分、具体原始设计意图及所用 SDK 版本作为私有来源保存；
资料原件不分发。仍须补齐实际施工图、材料、载荷、公差、配合、制造、检验和
最终计量。开发回放改进需要与原图比较，RRSI 方法净收益另按冻结合同检验。
