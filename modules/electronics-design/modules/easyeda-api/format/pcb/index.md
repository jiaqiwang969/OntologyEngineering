# PCB 格式文档

本章节详细介绍了嘉立创EDA PCB文件的格式规范。PCB文件主要包含以下几个部分：

- [通用格式](common.md)：文档头、画布、层、物理层、偏好等。
- [分区格式](partition.md)：分区定义。
- [基础图元](primitive.md)：网络、图元配置、分组、丝印配置、关联、属性等。
- [焊盘与过孔](pad_via.md)：焊盘和过孔。
- [形状图元](shape.md)：直线、圆弧、多边形体系、折线、填充、区域、覆铜、图片、泪滴等。
- [二进制对象](obj.md)：内嵌对象。
- [3D 外壳](3d.md)：外壳、折痕、实体、螺丝柱。
- [文字体系](text.md)：文字。
- [属性](attr.md)：属性。
- [尺寸工具](dimension.md)：尺寸标注。
- [封装体系](component.md)：元件实例。
- [设计规则](rule.md)：规则模板、规则定义、规则选择器。
- [拼版](panel.md)：拼版参数。
