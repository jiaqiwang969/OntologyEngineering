# 工程交付的依赖与证据

整体重构中。工具执行、语义检查、数值符合、工程采用和整机成熟度分别记录。一个局部机构的原生进展不覆盖整机设计；旧 workspace 状态也不能抹掉较新的受控 CAD 记录。

同一 Project/Harness 持续组织：用户目的/验收 → 必要功能 → 机理/边界 → 结构与接口 → 候选取舍 → 资料/计算/试验 → 有范围的决定 → CAD、制造、装配、检验与交付 → 变化后的重审。agent 维护合同，不要求用户手填 RDF。新学习的方法与来源继续进入这条链。

| 必要工作 | 具体证据义务与当前入口 | 交付前的依赖 |
|---|---|---|
| 恢复要求与纠正 | `knowledge intake` 保留原消息字节/身份、失败/停止与未读范围；当前授权决定案例角色 | 成功案例不重开原交付；开发已读材料不冒称未见任务 |
| 从专利/视频推导机构 | 图文、时间点/帧 → 观察 → 必要功能 → 本机候选 → 待核假设 → 验证；知识来源带版次/页/提取身份 | 视频未见的尺寸、载荷、材料、内构造、真空能力仍未知；观察不等于机理已证实 |
| 定义主要功能 | 定心、轴向定位、相位、传矩、承重；吸持/初粘/释吸/退头/压辊接管；换型、装卸、维护和恢复 | 每次接管有承担对象、条件、计算/实测和失败路径；接触或无干涉不能代替传力/保持 |
| 当前工程判断 | `project work /3` 按缺口本地查原页、检查模型前提和功能承接；Agent 据原件和完整条件审阅 | 工程事实与假设分开；语义、模型、原生 CAD、仿真、实测各支持自己的主张 |
| 数值验收 | 同一 Project 的 `numeric_acceptance`，要求/单位/状态/基准/来源与模型或观测绑定 | 最终目标必须对应最终状态；局部轴、仿射矩阵、两个对齐点或未标定仿真不替代最终测量 |
| 运动与原生 CAD | `cad motion` 核对坐标、角度、位移、时基和耦合；`cad nx` 记录真实工具/输入/进程/结果 | 全程包络含管线、工具、接头、附件和柔性尾段；共享坐标/参数/轨迹后再输出完整动画 |
| 参数改型与配合 | `cad variant` 的源绑定设计意图、控制件/成员、刚体变换和原生孔轴回读 | 变化后重开配合、尺寸引用、视图、排版和清单；新样件生成不覆盖任意旧特征树维护 |
| 图纸、BOM和审核包 | `cad drawing audit-packet` 与原生保存/独立重开；既有 CAD handoff | 可加工零件图/装配图需要完整尺寸、公差、材料、表面、工序、基准、接口、检验与同版 BOM；存在图框不算完成 |
| 制造、装配、检验与成本 | `oe-cad::handoff`、制造报告与 Project 支持依赖 | 工艺替代后的密封/隔离/支承等功能有承接；夹具/装卸可行；成本批次/准备/返修/良品/损失、报价与交期有依据，缺项不填零 |
| 电气/气动/控制 | 与机械接口、状态、限位、回零、互锁和故障恢复共用版本 | 当前具体执行/原生/现场能力逐项验收；未实现的能力不由共享字段存在替代 |
| 经验与系统改进 | 现有 knowledge/Harness 和有界 RRSI 冻结、评估、反馈、拒绝/恢复 | 方法改进与领域本体候选分别取证；无收益保持基线，完整新拒绝历史保留 |

《工程本体论》用于对象、关系、术语与适用条件；《产品可信工程》用于主张、证据、范围和变化。Roloff/Matek 用于承载与刚度，Norton 用于机构与运动，公差计量教材用于状态/基准/合格判断，DFMA 用于制造装配和成本。资料选择由缺口决定，不能为了“六书覆盖”套用不相关工序或价格。米思米离线页用于条件与限制，在线完整型号/配置、规格、CAD 和采购信息另按当前身份取证。

## 从受控局部设计到整机交付

先恢复最新受控设计、历史基线和用户纠正；将局部假设、实际原生成果与整机成熟度分开。沿当前拓扑检查共同升降与独立调节、沉入盖板/退出空间、主要功能接管、完整包络和装卸维护路径。现场未知只阻止依赖它的采用，其他有源的几何、运动、接口、原生回读与局部试制图继续推进。

局部试制图须写明试验目的、对象/版本、边界和待核材料/载荷，不能伪装量产放行。取得质量/负载/真空/接触摩擦/螺纹与材料依据后再计算和试验；共享轨迹、坐标、零位、时间及异常恢复合同再驱动 CAD 与完整流程动画。主接口冻结并通过版本复核后出零件图、装配图、BOM、电气/气动/控制接口及检验文件。

最终数值验收要固定物理对象、最终状态、基准、口径、覆盖和不确定度；草案不能自行升级为用户确认。实际样机的重复测量、装卸换型、全过程保持、制造与检验记录支持最终决定。新反例或接口/工艺变化由 Project 重开相关计算、运动、图纸、工艺、检验、成本和交期，历史不覆盖。

本轮实际接续记录保存在私有维护记录中，包含原过程/未读范围、独立预期、源码/生成身份、当前 NX 回执和有限方法反馈。私有项目原文、原 CAD、原图及会话不进入可分发包。字段、文件或案例数量不是全体系完成比例。

后续完整上下文/尺寸关联记录同样保存在私有维护记录中。历史版本已记录真实局部机构的背景、缺口与当时审查，并在 Rust/NX 中补尺寸关联读取及保存重开核对；这些记录保留原执行身份，不能替代当前版本和当前 Project 的验证。当前仍须取得意图正确性、图面视觉、统一全局时基、承托接管、真实螺纹与最终计量证据，才能支持具体设计和试制决定。两卷方法书继续用于对象/条件与主张范围，教材/供应商按这些缺口查证，不以多调用或引用数量替代它们。

当前新增局部执行：独立设计记录里的圆边和中心距要求已驱动Rust/NX创建模型空间关联标注，保存后另进程重开，并进入同一Project的原任务来源核验。该实例回答“标注是否关联到要求的两处几何、原生数值是否相符”；材料、保持载荷、配合/制造公差、图纸视图/排版和校准仍未知。局部尺寸证据支持图纸设计义务的下一步，尚不支持加工放行或最终贴后精度。

方法反馈继续分层：闭合成功案例提供先声明特征/配合/图纸依赖的方法；下一已读任务实际采用并取得有范围CAD证据，已有对象/条件/来源/决定表达足够，保存实例/no_delta。发现的声明投影来源缺陷作为软件修复处理，不晋升工程规律。下一轮先把有界模型空间标注续成可核验图纸sheet与视图，再在批准的接口/材料/载荷及测量范围内推进试制和检验。
