# 制造工艺与成本管理方法 0.5.5

本版承接 [0.5.4](manufacturing-method-0.5.4.md)，将 CAD Agent 从冷板焊接示例中的“几何到工艺”交接，扩展为[通用 CAD 工程入口](../../skills/cad-agent/references/cad-engineering-workflow.md)。零件、图纸/BOM、装配、机构和制造需求共用来源、配置、身份、关系、主张及变化影响的表达；焊接保留为一个示例，不限定 CAD Agent 的能力范围。

新增 `cad-evidence/v1` 合同和完整性适配器，核对项目内相对来源、SHA-256、原生回读 JSON Pointer、声明值、对象引用及断裂的支持链，并输出项目 ABox 和影响提示。制造交接的 v1 合同增加向后兼容的 `cad_evidence` 引用，能把确切 CAD 对象链到特征、功能、路线、工序、主张或问题。CAD 包、制造包和 Semantica 的职责保持分开：证据完整性不等于工程性能；Semantica 是唯一正式语义执行面，且不替代实物试验或产品放行。

[能力边界](../cad-agent-capability-map.md)明确本公开便携版的可执行工具：本机 Fusion 守卫、通用证据核验和制造交接。NX/AutoCAD 远程桥、完整装配重建/动画和机构求解器尚未纳入公开便携包；它们的经核验输出可以使用同一合同接入。真实客户模型、图纸、人物对话与商业参数不在公开包中。制造语义冻结包仍为 `0.1.1` 候选；本次方法/工具变更没有冒充新的 Semantica promotion。

方法版本为 `0.5.5`。记录模板、报告组件、评审卡、Semantica 运行时与 Fusion wheel 沿用 0.5.4 锁定版本；各自版本不因方法版号自动升级。发布包的精确清单、哈希和验证范围以对应 Release 附件及接收方复验结果为准。

独立核心按 104 个逐文件登记的通用资产构建；在全新目录验证了文件闭包、Semantica 唯一后端、5 项通用 CAD 证据测试、6 项 CAD／工艺交接测试、3 项制造投影测试和 68 个冻结合成制造场景。仓库测试为 173 项通过。核心 ZIP 的 SHA-256 为 `fa6c94a69e9f72e0db62a1af07ae937184403fcd14b9b53461a14455b3f5cb81`。这些结果不证明具体客户产品或现场制造能力。
