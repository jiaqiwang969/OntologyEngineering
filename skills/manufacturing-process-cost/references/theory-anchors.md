# 工程本体论概念锚点（独立核心版）

本模块使用根 [工程本体论](../../../SKILL.md) 的对象、身份、证据、关系与因果方法。原书稿不随核心包分发，下面的锚点只给出本模块采用的操作定义。

| 工程问题 | 本体论操作 |
| --- | --- |
| 原话是什么意思 | 保留原话来源，提出可检验的能力问题（CQ），与提出者回读 |
| 图纸与模型对应吗 | 区分对象身份、配置、版次与产品状态 |
| 条件没有写全 | 未知保持 OWA；只在证据证明的局部范围使用 CWA |
| 谁能做决定 | 分离提出、执行、复核、接受与对外发布角色 |
| 旧经验能沿用吗 | 比较使用情境、必要功能、失败路径和反证条件 |
| 验证结果说明什么 | 绑定对象、方法、条件、判据、时间与适用范围 |
| 改变工艺后查哪里 | 沿功能、检验、资源、成本、交期和输出的依赖追踪 |
