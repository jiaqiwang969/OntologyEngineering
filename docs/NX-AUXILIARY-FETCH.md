# 大任务辅助回执取回

新 `oev2.nx-native-job/3` 可以在任务正本声明 `auxiliary_capacity`：`max_total_bytes`、`max_file_bytes`、`max_files`。该字段进入任务摘要，必须在创建任务和来源计划前确定；不得给旧任务或旧unknown补写预算。

例如 `{"max_total_bytes":536870912,"max_file_bytes":67108864,"max_files":8192}` 可容纳4555原回执以及新索引页、字段块和控制记录。控制器和接收端分别检查完整清单、实际单文件、总字节和数量；不会为满足预算删去原回执。数量上限65536，总量512MiB和辅助单文件64MiB上限保持，控制记录4MiB、原帧/分段及总范围数量上限也保持。

缺省字段的旧v2和v3仍使用1088辅助文件限制，序列化不添加null，原任务摘要不改变。v2携带新声明会被拒绝。读取更多字节只证明完整运输；原生执行、独立重开、工程采用和旧unknown保持各自身份及证据要求。

软件回归包含4555回执、18页、20块，以及旧边界/容量/摘要反例。Windows测试需实际运行独立controller取回1100回执并核全文件摘要；Mac编译不验证Windows分支，原生NX任务另验。
