# S01 course-roadmap memory

## Source-grounded interpretation

S01 is a course orientation. It enumerates source lessons 2 through 14 and previews their goals. It is not a mode inspection and does not provide enough information to reproduce geometry.

## Operational rule

For an orientation-only lesson:

1. Learn by extracting every downstream learning group, source anchor, objective, and planned product.
2. Contact Fusion with read-only probes that map future topics to current capabilities.
3. Internalize the roadmap, version boundary, deferred mappings, and next-lesson handoff.
4. Do not create decorative geometry merely to satisfy a practice slot.
5. Preserve frozen metadata disagreements as explicit correction candidates.
6. Begin the next cycle with learning the next lesson.

Capability presence means the environment can support later practice. It does not mean the skill has been learned.

## Current contact boundary

The S01 contact used Fusion version 2704.1.23 with Chinese localization. It found Design, Drawing, Assemble, Render, Animation, and Form workspaces and the expected core parametric and assembly API surfaces.

Transfer intent and stable feature concepts from the 2023 English source. Re-discover current command names and locations. Never encode old pixel positions as ontology knowledge.

## Evaluation boundary

S01 may be accepted for curriculum progression, but it is not production proof. Semantic release and production activation remain separately gated.
