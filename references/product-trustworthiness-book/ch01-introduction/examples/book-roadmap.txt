# 全书知识地图与阅读路径
# Book Roadmap and Reading Paths
#
# 全书思路（2026-08-15 作者裁决，见 notes/book-architecture-iso-axis-decision.md）：
#   前十章 = AI 之前的世界：按 ISO 26262 规范，讲透传统功能安全最佳实践；
#   后十章 = AI 之后的世界：用工程本体论把前十章的 ISO 工程逐一本体化。
# 本文件承接第 1 章正文移出的逐章预告；正文只保留十问十答对应表。
# 第 3—20 章尚未解锁施工，本文件随各章解锁与冻结逐步修订。

# ==============================
# 0. 总设计：两个时代的对照，10+10 镜像
# ==============================
#
# 前十章每章约七成篇幅讲该 ISO Part 的传统最佳实践（场景先行、误判先行、命题后置），
# 约三成篇幅暴露"AI 之前做法的极限"，章末冻结问题合同交给镜像章。
# 后十章从对应问题合同出发建立独立工程本体（TBox/ABox/CQ/门禁），
# 并展示 LLM/Skill/Agent 在其边界内工作；共享方法，不共享业务事实，不合并超级本体。
#
# 汽车功能安全（ISO 26262）是全书主线；ENV-01 跨域投影证明问法可迁移、答案不可迁移。

# 2. 后十章（AI 之后：ISO 工程本体化）
# ==============================
#
# 第 11 章 可信判断本体：把第 1 章的"可签主张"建成绑定对象/配置/证据/决定的结构
# 第 12 章 身份与概念本体：把第 2 章的术语体系变成机器可查的身份判据与概念约定
# 第 13 章 治理与责任本体：把第 3 章的角色/确认措施/授权写成显式关系与门禁
# 第 14 章 情境与危害本体：把第 4 章的 HARA 变成可推理的情境、事件与分级结构
# 第 15 章 需求与追溯本体：把第 5 章的派生/分配/接口连成不丢失的追溯链
# 第 16 章 测量与证据本体：把第 6 章的度量与数字绑定方法/单位/不确定度/来源
# 第 17 章 版本与变化本体：把第 7 章的构建/回归/漂移放上同一条时间线
# 第 18 章 依赖与独立性本体：把第 8 章的分解/共存/DFA 变成显式依赖图与检查
# 第 19 章 制造与现场本体：把第 9 章的批次/单件/现场信号连回设计定义
# 第 20 章 发布与保证本体：把第 10 章的基线/证据包/授权组织成持续保证决定
#
# 每章展示：问题合同 → 最小概念化 → 正反例门禁 → LLM/Skill/Agent 的有界工作。
# 大语言模型负责理解与翻译，技能约束方法，Agent 执行有界动作；
# 任何自动化能力都不自动获得放行权。

# 4. 三条阅读路径
# ==============================
#
# 路径一：顺读路径（系统学习 / 团队共读）
#   1 → 2 → … → 10 → 11 → … → 20
#   先在 AI 之前的世界学会传统做法，再看同一套知识如何被本体化。

#   重点观察：你熟悉的每个工作产物在本体世界里变成了什么。

# 路径三：AI 工程师路径（把 LLM/Agent 引入工程的人）
#   1 → 2(术语) → 11(主张结构) → 12(身份) → 13(治理) → 17(版本) → 20(执行回读)
#   重点观察：Agent 在什么条件下获得行动边界，在哪里必须把判断交还给事实与责任人。
