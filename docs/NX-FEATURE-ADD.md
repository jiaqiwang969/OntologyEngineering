# 在当前原型上新增通孔

`add_hole_feature` 使用显式 `oev2.nx-feature-add-params/1`：`intent` 引用 `NxFeatureAddIntent1`，`budget` 复用原装配预算。共享意图和原始调用返回由 `specs/modules/cad-engineering-binding.toml` 经锁定 ggen 生成。该候选用于当前来源副本上的实际减圆柱开孔；软件、当前 Windows/NX、保存重开、发行选用及工程采用分别验收，维护回执决定当前状态。

范围是毫米制、单实体矩形板，已有一个竖直圆通孔，新增另一个不相交且完全位于板内的竖直圆通孔。意图绑定当前对象版本及 PRT 摘要、完整装配来源闭包、目标原型、独立目标/保留孔、板界、工具原点与上端、来源。工具沿原型 +Z 穿透板，圆柱类型须实际返回 CYLINDER。不得重建名义板、换回历史文件、复用旧进程 tag 或将相似几何冒充真实修改。

复用原来源闭包、装配、参考集、详细几何及两态板检查 owner。内部将新增意图投影到已有板几何检查所需字段，仅检查两种状态及不变关系；不序列化为删除任务，不改写原输入、观察、事件或删除合同。已有 `delete_hole_feature`、其失败和原验收保持。

调用前完整核目标孔不存在、已有孔上下圆及柱面、六外平面、精确外界、单实体、原生体积和全部特征。原生边界再核当前 work part、prototype body 与 owner，以已使用的 NX 2412 `UF_MODL_create_cyl1` / negative sign ABI 创建，并保存原始返回 tag、尺寸、返回码和一次 update 结果。部分失败保留真实观察，不重试创建或保存。

调用后完整特征清单必须只多一个与原始返回相同的特征；其当前 owner/body、类型、位置及实际目标柱面唯一对应。旧特征的同进程身份、类型和位置保留；面 tag 可能因布尔运算改变，几何完整域另验，不宣称持久拓扑身份。目标孔圆边从零变两条，全圆边从二变四，完整面从七变八；原孔、外界、销轴、实例关系/位姿及参考集保持。体积按独立板减圆柱式核对，原 `1e-12 m³` 判据不变。

装配观察结束时会选回装配根；特征枚举依赖目标板原型的当前工作零件。流程在每次枚举前显式选择目标原型，保留原生 owner/body/work-part 检查。切换失败立即停止，已经返回的创建或保存结果保留，不重复创建或保存。状态化软件控制覆盖这一上下文转换及保存前后切换失败；来源是现有装配 owner 与原生失败，不能替代当前 Windows/NX 验收。此修正保持 `/1` 的输入输出与几何判据含义，属于调用顺序修复。

只有以上通过后才保存任务副本的完整来源闭包；保存后再次核同样的几何、特征、体积与装配。readback 保留各原始事件引用，明确 `independent_reopen_checked=false` 与 `engineering_adoption=not_assessed`。独立新进程重开、完整三配对干涉、变化影响、制造和实物计量继续作为不同义务；本轮受控案例属于 development_replay。

Mac 软件控制覆盖错误来源、已存在目标、外形/保留孔变化、缺失或歧义清单、旧 tag 冒充新增、错误 owner/body/type、额外新增或原特征丢失、原始返回错误和部分保存。当前 Windows SDK 执行及原生事实必须重新取得，不能用这些合成控制或旧发行接收代替。

`cad evidence verify-addition` 接收 `CadFeatureAddRequest1`：原 `CadCorrespondenceRequest1` 中的 `new` 声明、旧新详细/装配观察、真实新增任务和当前 Project 来源分别绑定。接收器重读原输入、原始事件、完整保存产物及独立进程重开。不能只靠孔已出现断言实际新增；同名原型路径按完整相对闭包匹配。CLI 复用原 correspondence、reconcile 和 impact，旧新依赖并集必须重审；不写原 Project，不自动采用，不把缺失链接当作全覆盖。
