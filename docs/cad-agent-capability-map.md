# CAD Agent 能力与公开边界

CAD Agent 是工程本体论下的通用 CAD 模块，焊接只是一个使用案例。它对所有工作先统一产品配置、状态、对象身份、来源、几何/关系证据、主张和反例；再按任务调用零件、图纸/BOM、装配、机构或制造专项工具。正式语义仍只由 Semantica 执行。

| 能力 | 通用方法与证据合同 | 本公开便携包的可执行范围 |
| --- | --- | --- |
| 零件设计、修复、导入与回读 | 定义、参数、特征、基准、尺寸来源、模型版次和保存后回读 | NXOpen/Journal 直连；其他 CAD 的经核验回读可导入 |
| 图纸、尺寸、公差与 BOM | 图纸权威、标注、定义/实例数量、来源和不一致问题 | 直接 NXOpen/Journal 与独立 PRT 回读；真实 NX 及授权由接收方配置 |
| 装配 | 实例身份、完整界面图、逐状态支撑、装入路径、工具空间、载荷路径与接头容量边界 | 公开通用判断内核及 AABB 固定方向装入/顺序筛查；真实接触、工具/手路径和物理强度另验 |
| 机构 | 运动拓扑、运动副、闭环分支、极位、运动包络和载荷边界 | 公开平面四连杆闭环位置筛查；复杂机构、连续运动和动力学另验 |
| CAD 与制造协同 | 同版对象到功能、工艺操作、检验、成本、交期的双向引用和变更影响 | 来源校验、项目 ABox 投影、双向问题与依赖影响可执行 |

公开便携包的“可运行”不等于真实 CAD 主机已接入或实物已验证。当前 CAD 执行不使用 MCP；历史桥协议测试不证明 NX 直连。新环境需检查实际版本、授权和原生保存/重开回读。装配/机构筛查器只覆盖各自有限几何域。装配与力学可迁移的是[对象、因果和证据边界](../skills/cad-agent/references/assembly-and-physics-kernel.md)，不是历史项目的装配步骤或仿真算法。历史案例、客户资料、现场配置和未清权参数未进入公开包。
