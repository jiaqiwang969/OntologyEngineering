# 实体对齐与消歧示例
# Entity Resolution and Disambiguation
#
# 同一台设备在不同系统中有不同标识——对齐是知识融合的第一关

# ==============================
# 1. 问题形态
# ==============================
# 同一实体多种写法（需合并）：
#   台账系统：  "3号数控车床"  (id=E0117)
#   MES系统：   "CNC-Lathe-003"
#   维修日志：  "3#车床" / "三号车床" / "L003"

# 不同实体同名（需区分）：
#   "加工中心" —— A车间的 VMC850 与 B车间的 VMC1060 都被这么叫

# ==============================
# 2. 第一层：规则归一化
# ==============================
# 编号正则归一：
#   "3号|3#|三号|No.3"  + "车床"  →  候选 Lathe_003
#   设备编号 "E0117" / "EQ-2023-0117" → 去前缀补零归一

# 别名表（最朴素也最有效）：
#   Lathe_003:  ["3号数控车床", "CNC-Lathe-003", "3#车床", "L003"]
#   维护成本低，命中即对齐；新别名出现时人工补一行

# 规格归一化：
#   功率 "15.5kW" / "15500W" / "15.5千瓦" → 15.5 (kW, xsd:float)
#   日期 "2026/3/21" / "26年3月21日"     → "2026-03-21"^^xsd:date

# ==============================
# 3. 第二层：相似度匹配
# ==============================
# 规则未命中时，计算候选对的加权相似度：
#   名称相似度（编辑距离/拼音）          权重 0.3
#   属性相似度（型号、功率、厂商一致性）  权重 0.4
#   关系相似度（所在工作单元、操作工重合）权重 0.3

# 判定阈值：
#   score ≥ 0.90  → 自动合并
#   0.70 ~ 0.90   → 进人工复核队列
#   score < 0.70  → 视为不同实体

# 示例：
#   ("3号车床", power=15.5, cell=A) vs (CNC-Lathe-003, power=15.5, cell=A)
#   名称0.6×0.3 + 属性1.0×0.4 + 关系1.0×0.3 = 0.88 → 人工复核 → 确认合并

# ==============================
# 4. 合并的表达：owl:sameAs 及其陷阱
# ==============================
# 确认对齐后的两种做法：

# 做法A：物理合并（推荐用于同一企业内部）
#   选定主IRI（mfg:Lathe_003），其余标识写成别名属性：
#   mfg:Lathe_003 mfg:hasAlias "CNC-Lathe-003", "3#车床" .

# 做法B：owl:sameAs 关联（用于跨系统联邦场景）
#   mes:CNC-Lathe-003 owl:sameAs mfg:Lathe_003 .
#   陷阱：sameAs是强语义——两个IRI的所有断言互相传播；
#   若对齐错误，错误属性会"传染"到正确实体。
#   联邦场景中宁可用弱关联 skos:closeMatch，确认后再升级为sameAs

# ==============================
# 5. 冲突消解
# ==============================
# 对齐后属性值冲突：台账说功率15.5，MES说11.0
# 消解策略（按优先级）：
#   (1) 来源可信度：台账(设备科维护) > MES配置 > 日志文本抽取
#   (2) 时效性：带时间戳的新值覆盖旧值（保留历史到具名图）
#   (3) 提交裁决：高价值字段（安全相关）冲突必须人工确认

# 溯源记录（与第5章PROV思想一致）：
#   每条三元组附带来源与时间元数据，
#   冲突裁决时可追溯"这个值是谁、什么时候、从哪个系统来的"

# ==============================
# 6. 工程建议
# ==============================
# 对齐质量直接决定图谱可信度，上线前用抽样审计：
#   随机抽200个合并决策人工复核，精确率应 ≥ 98%
# 阈值不是一次定终身：每月用复核队列的人工标注回归调参
