# 合成演练：先核实什么，再投入多少

本例全部为教学合成：通用定位座、数值、答复与试验结果均不来自客户产品。只比较一个 24 件订单的局部加工工作包，币种为元、未税；不构成整件报价、现场能力或采购批准。各轮顺序揭示，不把后轮答复提前用于第一轮。

## 第一轮：三种选择，先找共同前提

产品版本 V1；设备可调配已确认。候选如下，费用范围已在本例内对齐；内部路线的固定费包含计划中的后续验证与交付检查，但这些工作尚未执行。下面的工时区间是估计，没有概率分布；若实际出现未包含的工作，必须另列并重算。

| 候选 | 已知费用模型，不含本轮探索费 | 关键未决项 |
| --- | --- | --- |
| 外协 O | 本工作包报价 7,200；范围、有效期和交期已核实 | 本例保留约定的交接与验收，不将报价本身当能力证据 |
| 拆分工序 D | 固定 1,800 + 按件 140 × 24 + 附加工时 h × 60，即 5,160 + 60h；h 暂估 12–30 小时/批 | 有效空间；指定区域接刀痕是否允许；增加装夹的工时与质量表现 |
| 专用夹具 J | 固定 3,000 + 按件 110 × 24 + 配研工时 g × 60，即 5,640 + 60g；g 暂估 2–24 小时/批 | 同一有效空间；实际贴合、重复定位与配研是否收敛 |

h、g 不含本轮探索用工，不与按件费用重复；两条内部路线互斥，不能把 D 的低固定费与 J 的低按件费拼成第四条路线。固定费尚未投入；探索试样为额外试样，不计入 24 件良品。

两条内部路线都依赖同一受控装夹配置的有效空间 H。教学条件规定 H 至少 180 mm；已有初查记录为 181 ± 3 mm，方法范围说明它尚不能支持“整个判定区间不低于 180 mm”。不能取中心值就关闭问题，也不能因此宣判两条路线都失败。

这个共同问题应先核实：它可能同时改变 D、J 的可用状态。设备让得出来已经有答复，不再重复询问排产。外协不依赖 H，但其交接要求仍保留。

## 第二轮：限定本轮投入，先写分支

本例负责人给出的探索费用上限为 600；目标是决定本单下一步，未批准整机研发。受控判定方法约定：H 的结果区间全部达到要求才支持该空间条件；若方法、配置或记录无效，本次不用于判定。这里的数值与判定规则仅服务本演练，不是通用计量规程。

| 动作 | 新增费用与时间 | 结果怎样改变下一步 |
| --- | --- | --- |
| 核对受控配置并复测 H | 120，2 人时；资源窗口已给定，可当日完成；D、J 共用一次 | 支持：继续查各路线条件；不支持：当前配置下两条都需调整或转 O；仍跨界：改善证据再判断；记录无效：保留费用与原因，重取有效证据 |
| 回读图纸，向设计责任方确认指定区域接刀痕 | 本例已完成内部准备，后续澄清不新增单列费用；答复历时未知 | 允许：只关闭该范围的允许性；不允许：当前 D 不适用；含糊：保留待定。均不取消图纸公差 |
| D 的一次有代表性拆分验证 | 新增 480，包含探索试样、测量、人工及设备占用；预计一个工作日窗口 | 在 H 及接刀痕允许性明确后进行；记录额外装夹、质量结果与 h 的更新依据；单次通过不证明整批能力 |
| J 的贴合与重复定位验证 | 新增 660；工期依实际试样条件确定 | 共用核实后已超本轮剩余预算，不在本轮启动；保留条件与费用，不称 J 永远不划算 |

图纸澄清与空间核实可以接续推进，不能把尚未收到的答复记为已确认。D 的验证是条件动作，不因两项工作正在进行就提前开工。预算约束属于这个合成任务，不给其他任务添加审批流程。

在探索开始前，分别看完整投入路径：

- 选 D：120 + 480 + 5,160 + 60h = **5,760 + 60h**；比 7,200 低需 **h < 24 小时/批**。估计区间对应 6,480–7,560，跨过经济界限。
- 选 J：120 + 660 + 5,640 + 60g = **6,420 + 60g**；比 7,200 低需 **g < 13 小时/批**。估计区间对应 6,540–7,860，同样跨界。
- 若两套都试，探索费是 120 + 480 + 660 = **1,260**，共用核实只算一次；已超过本轮上限。

这里没有成功概率，不能算“平均预计省多少钱”，也不能仅凭最有利情景支持投入。当前可建议先做共同核实和澄清；满足条件后，D 的局部验证在 600 范围内。是否采用某条生产路线，还取决于验证结果、剩余工作和交期。探索预算获准不等于生产路线获准。

## 第三轮：拿到结果，更新两笔账

本轮新增的合成记录：

1. 同一受控配置复测 H 为 184 ± 1 mm，方法与记录有效，按预定规则支持空间条件；结果同时连到 D、J。
2. 设计责任方明确允许指定非功能区域的接刀痕，其他公差不变；仅关闭 D 的这一要求问题。
3. 随后完成 D 的局部验证，探索资源费用共发生 600。该试样检查满足本轮判据；人员记录修正了装夹估计，h 的整批预测由 12–30 改为 24–28 小时。**24–28 仍为预测，不是 24 件已经做完的实绩。** 计划中的后续能力确认仍须完成，费用已在本例固定费中预留。

现在只比较 D 与 O 的续行费用；J 尚未试，不宣称找到所有路线中的最优解。

| 所问的问题 | 计算与判断 |
| --- | --- |
| 从现在起，D 与 O 哪个新增费用更低？ | 已发生 600 对两者相同。D 剩余为 5,160 + 60 × (24–28) = **6,600–6,840**；O 剩余仍为 **7,200**。D 在此费用范围内低 360–600，但继续生产仍受未完成的能力确认约束 |
| 这轮探索是否已经实现降本？ | 没有。继续 D 的累计预测为 600 + 6,600–6,840 = **7,200–7,440**；与从起点直接选 O 的 7,200 相比，当前预测为持平至多支出 240，且尚非实绩 |
| 现在转 O 的累计预测是多少？ | 已发生 600 + 外协 7,200 = **7,800**。不能用这 600 强迫继续 D，也不能在复盘时删掉它 |
| 经济界限为什么变了？ | 起点含探索费时 D 需 h < 24；探索费已不可收回后，续行比较是 5,160 + 60h < 7,200，即 **h < 34**。两个界限回答不同时间点的问题，没有互相矛盾 |

费用预测支持“在剩余质量条件成立时，继续 D 比此刻转 O 少花钱”，不支持“探索已经省下了钱”，也不支持跳过验证。若新增返工、延期或未包含验证费，要同时重算续行选择和累计预测。未落实的下一张订单不能用于摊薄本单探索费。

## 换一种结果时怎样处理

- H 仍跨界：D、J 的共用前提继续待核；不把两个未知候选自动淘汰。根据可取得的有效证据、期限与投入重新选动作。
- D 试样的测量用了错误基准：保留试验和费用，撤回相应支持；质量结论无效不使独立有效的 H 记录失效。检查成本测时是否也受影响，分别处理。
- 客户后来禁止原区域接刀痕：重开 D 的要求与路线，沿依赖检查工序、工装、报价和输出；J 的贴合问题不会因此自动关闭。
- 订单数量或产品版本改变：重算各路线专用投入、按件费用、供方阶梯价与验证覆盖，不沿用原来的 24 或 34 小时界限。

把过程接到既有问题、候选和修订记录即可。方法见 [P05/P11](../../../references/decision-patterns.md)，选用[卡 4 和卡 5](../../templates/decision-review-cards.md)。本例是人工判断与费用演练，不是新增 JSON 报告输入、Semantica 场景或自动投资决策器。
