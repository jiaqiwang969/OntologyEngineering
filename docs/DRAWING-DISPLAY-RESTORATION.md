# 图页显示的原 WCS 身份恢复

显式 display intent/2 与 params/2 接续上一版完整显示状态未恢复的真实反例。
原 /1 的文本、执行和恢复检查保持；/2 将首行缩为 `UPPER/LOWER CTRS`，
CTRS 在本合同中表示原父引用的名义圆心，第二行仍是 `MODEL Z=<原坐标> mm`。
这不增加制造公差或标准符合性主张，图面空间和可读性须检查实际 PDF。

同一 Project/work/Harness 和 `drawing_identification` owner 执行有源副本试验。
在附注后、显示设置后、装饰回读后、导出后和身份恢复前采集显示清单。
这些观察用于定位变化，不能仅凭先后顺序宣称根因。原失败与独立预期保留。

原生 ABI 仅使用安装 SDK 的 `UF_CSYS_set_wcs`：原 tag 必须属于当前进程、
仍 alive、属于本零件且类型是坐标系；读取当前 WCS，仅在不同身份时调用，
再读取并要求恰为原 tag。失效或来源不明时拒绝，不新建、删除、转换或保存对象。
SDK 明确要求 prototype coordinate system；occurrence 或 SDK 拒绝保留为失败。

恢复先尝试全部附注及 WCS 可见性，再尝试 WCS 身份和所选非 WCS 显示状态。
每个原生恢复失败均保留，后续恢复仍尝试。原始完整清单必须精确相等，
不忽略 tag、单位、类型、方向阵、显示属性或未知。全部原几何、关联尺寸、
来源及副本字节检查继续；成功导出文件不能覆盖恢复失败。

规范位于既有 nx-sheet-dimensions 片段，经锁定 ggen 生成共享合同。
Rust owner 与安装 NX 2412 SDK 的窄 C++ ABI 分别核验，Mac 检查和同源 Windows
构建之后才允许新的原生试验。冻结测试保留 /1 文本、版本匹配、身份失效、
恢复错误、部分失败、阶段记录及最终清单漂移反例。真实原生结果、PDF 可读性、
正式选用与工程采用分别登记；原63项目标、完整Semantica及制造检验/最终计量保持。
