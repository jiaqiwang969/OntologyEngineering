# Chapter 1: Introduction — From Philosophical to Engineering Ontology

## 本章内容

本章是全书的开篇，回答三个问题：本体论从哪里来（哲学源头）、
工程本体论研究什么（形式化、可计算的知识结构）、
为什么 AI 时代它变得不可或缺（大模型的幻觉问题与知识权威源）。

## 核心观点

| 维度 | 哲学本体论 | 工程本体论 |
|------|-----------|-----------|
| 研究对象 | 存在的本质、世界的本源 | 领域概念、关系与规则的形式化表示 |
| 方法 | 思辨、追问 | 建模、形式化、计算 |
| 判据 | 无法收敛（高熵） | 一致性可检验、可推理（低熵） |
| 产出 | 哲学体系 | 可被机器处理的知识结构 |

## 经典定义

> **Gruber (1993)**: "An ontology is an explicit specification of a conceptualization."
> （本体是概念化的显式规范）
>
> **Studer et al. (1998)** 综合扩展为：本体是**共享**概念化的**形式化**、**显式**规范
> —— 四个关键词：概念化、显式、形式化、共享。
