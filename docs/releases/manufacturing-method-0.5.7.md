# 制造工艺与成本管理方法 0.5.7

本版补上 CAD Agent 从稀疏资料反推形态和机构的一段通用方法。图片、视频、专利图文或残缺 CAD 可以给出可见部件、轮廓、动作与局部关系；物理定律、机构约束和数学模型进一步排除不可能的结构、推出条件性数值或范围，并指出仍不可辨识的隐藏部分。可实施的 CAD 候选与原设备的真实内部结构分别报告。

新增[证据驱动的重建方法](../../skills/cad-agent/references/evidence-driven-reconstruction.md)和[推导记录合同](../../skills/cad-agent/contracts/analysis-record.v1.schema.json)。CAD 证据适配器现在可分别记录原媒体、专利和第一性原理推导；解析/数值结果必须绑定确切 JSON 字段，数值计算必须指向其实现来源。结构检查拒绝把推断关系标成观察事实，也拒绝缺少来源哈希、模型适用域或反证方法的推导记录。该检查只验证记录完整性和来源一致性，不判断图像内容、方程正确性或原设备的真实构造。

方法与记录合同不包含历史项目的图片、视频、专利副本、结构尺寸或仿真参数。正式 TBox、CQ、SHACL 和项目语义审查仍只由 Semantica 执行；本次没有晋升新的行业语义规则，学习结论为 `no_delta`。后续制造路线如果依赖逆推得到的界面或运动关系，仍须经 CAD／工艺交接，并保留验证问题。

验证：仓库测试 175 项及 59 项子测试通过；CAD 证据 6/6、工艺交接 6/6、远程桥与有界装配/机构 5/5、制造投影 3/3 通过；68/68 个冻结合成制造场景在源码和新目录核心包均通过。严格单一语义后端门禁、文件闭包及隐私扫描通过。验证只覆盖来源/记录结构、合成输入和列出的有限求解域，不替代具体形状识别、方程复核、真实 CAD 主机或实物试验。

安装步骤见[独立分发说明](../PORTABLE-DISTRIBUTION.md)。前版已有的两卷书与锁定 Semantica wheel 的书源绑定检查仍有 46/238 项被阻断；本次 CAD 方法更新未修改书源或绕过门禁。
