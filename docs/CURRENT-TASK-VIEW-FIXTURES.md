# 当前任务视图的独立样例

`crates/oe-engineering/tests/fixtures/current-task-view` 随代码携带十三组原有独立合成样例。每组保留原 Project、四份来源文本和 `EXPECTED.json` 的完整原字节。它们检查条件变化、失效来源、删除的前提或依赖、同版本采用变化、来源漂移、无关决定、明确未知、没有模型调用及旧视图拒绝；没有新增或放宽预期。

`current_task_view` 测试默认读取本 crate 内的这些样例。需要检查另一份明确输入时，可设置 `OE_CURRENT_TASK_VIEW_FIXTURE_ROOT`；环境变量是输入位置选择，不授予来源真实性或工程采用。

真实项目集成测试仍使用原有显式私有输入及其原预期，保留原 `ignore` 与单独执行身份。本目录不包含真实项目、聊天档案、书籍、凭据或其替代正文。合成样例验证任务视图行为，不证明工业方法收益、现场量测或完整项目合格。
