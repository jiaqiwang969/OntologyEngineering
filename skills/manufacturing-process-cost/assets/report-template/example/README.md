# 四轮合成演变样例

文件均为教学合成输入，不含客户原件或来自真实生产的测量。产品为通用定位支架组件；资料摘录用来演练来源、对象、判断、费用和反馈之间的关系。

| 输入 | 当前新增内容 | 建议先完成的工作 |
| --- | --- | --- |
| [01-inquiry.json](01-inquiry.json) | 不完整询问、相近制造经验 | 判断能继续做什么，缩小下一问 |
| [02-technical.json](02-technical.json) | 数量、产品版次、定位面变化与旧报价范围 | 更新工艺检验问题，保留未答范围 |
| [03-resource-cost.json](03-resource-cost.json) | 设备声明、材料/加工/准备费，其他费用未知 | 形成有条件的小计，指出能力缺口 |
| [04-feedback.json](04-feedback.json) | 两件首件记录、费用补充及加工估算修订 | 收窄能力结论，修订预算，接续整批反馈 |

每轮是独立冻结的报告输入，只含当时可用来源；同一对象与记录尽量保留 ID，产品版次与文档版次分开。视图随决定改变，四个文件名不代表制造行业的固定阶段模型。

行为试用应逐轮揭示文件；先完整读完四轮再解释第一轮不属于无未来信息的试用。生成器只读取指定的一个 JSON，不打开本目录其他轮次。来源 ID 的轮次约束由样例测试验证，不以文件顺序替代来源真实性检查。

另外五份 Markdown 是人工推演练习，不是生成器输入：[费用选择与证据降级](05-decision-review.md)、[工序拆分、时间与预算反馈](06-process-feedback.md)、[验证排序、改选界限与累计投入](07-validation-choice.md)、[变更适用范围、旧证据与分组费用](08-change-applicability.md)、[估算依据、批次与费用范围](09-estimate-basis.md)。

使用命令和范围见 [报告设计](../../../references/report-design.md)。不要将样例文字或金额作为新客户事实；复制其结构到项目工作区后，按新项目来源重新填入。
