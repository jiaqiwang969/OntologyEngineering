# 制造工艺与成本管理方法 0.5.6

本版承接 [0.5.5](manufacturing-method-0.5.5.md)，把 CAD Agent 已声明但未公开运行的部分做成可配置工具，并把装配及相关力学经验抽象为跨产品的判断内核。主线仍是来源与对象身份 → 工程主张与反证 → 原生/仿真/实测证据 → CAD 与制造双向交接 → Semantica 正式语义审查。

公开核心新增：

- NX MCP 的 SSH/stdin 一次性传输桥；AutoCAD 的独立 COM MCP 服务和登录桌面会话 relay。接收方提供自己的 CAD 软件、NX sidecar、SSH 别名和许可。离线协议回归不等于新主机的实机验收。
- 装配的定义/实例、完整界面图、逐动作状态、临时支撑、装入路径、载荷路径、接头容量与实物主张之间的通用因果区分。方法来自多种装配情境的失败与反事实观察；具体积木步骤、历史机器人/车型项目参数和私有仿真记录未复制进来。
- 两个有界专项工具：AABB 固定方向装入/顺序筛查，以及平面四连杆双分支位置筛查。它们提供可重复的局部工程诊断，不代表完整装配规划、接触力、动力学或实物强度已经得到验证。

CAD 工具仍只报告实际观察与计算。新的项目 ABox、方法文字和局部求解器不是正式 TBox/CQ/SHACL 正本；Semantica 仍是唯一可执行语义权威。本版没有将项目中的材料、尺寸、接触曲线或成功率提升为行业规律，语义学习状态为 `no_delta`，冻结制造语义包继续为 `0.1.1` 技术候选。

范围和运行依赖见 [CAD 能力图](../cad-agent-capability-map.md)、[远程桥](../../skills/cad-agent/remote/README.md)、[装配与力学内核](../../skills/cad-agent/references/assembly-and-physics-kernel.md)和 [独立分发说明](../PORTABLE-DISTRIBUTION.md)。真实客户证据、工作站配置、未清权历史车型/MATLAB 来源及外部 CAD 软件均不进入核心包。完整仓库快照与独立核心包的权利边界仍分别说明。

本版 CAD 与制造核心验证通过，但完整仓库的两卷书绑定检查 `semantica package verify-books` 仍返回 `book_source_binding_failed`：238 项中 46 项的书源摘要与锁定 wheel 不符。这是此前已有的书源/语义包收敛问题；本版不修改书源或绕过门禁，完整仓库的 `demos` CI 因而可能继续失败。它不改变独立核心包的文件完整性与 68 个合成制造场景的已执行结果。
