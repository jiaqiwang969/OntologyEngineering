# 大纲目录的权威边界

本目录保存写作过程资料，不是发布门禁，也不是机器执行入口。

- `ch01-outline.md` 至 `ch10-outline.md` 对应十个问题章的工作大纲。
- `ch11-outline.md` 对应已归档的旧“综合收口”案例，不是现行第 11 章《可信主张本体》的大纲；
  它的机器后继只在 `semantica.chapter_packages.vol2.ch20` 登记。
- 现行第 11–20 章没有十份追溯补造的大纲。它们各自的 `chapter.md` 是人读来源，
  `semantica.chapter_packages.vol2.ch11` 至 `ch20` 是唯一机器语义。
- `book-allocation.yaml` 只冻结早期字数分配的历史快照。历史目标、章内后续预算和当前
  实际篇幅相互冲突时，不以任何一组字数裁决发布。

所有 Vol.2 chapter packages 当前均为 `partial`、release `blocked`。大纲、正文、索引或
历史案例都不得作为 Semantica 的 fallback，也不得把场景通过改写成 package 已发布。
