# 链接器文件输入 /7

原生构建 pair07 在 thiserror-impl 动态库链接时真实拒绝了 `-Wl,-exported_symbols_list`。原临时 list、symbols.o 已不可用的字节继续未知；不能从后来文件或合成测试恢复该轮通过。

本模块先在 specs 正本说明含义，由锁定 ggen 生成三个 DTO 和一个 port，再由 Rust 读取完整原件并按每个参数位置留存独立字节。它借用既有 SkillRoot 与 /3 archive 输入核验，保留重复参数和全部普通参数，不创建另一个数据集、注册表或进程 owner。原 /3 隐藏文件拒绝保留。

本显式 /7 只处理直接或分开的 `-Wl,` 导出符号清单；合并逗号、隐藏 response、目录逃逸及其他文件语法保持拒绝或由旧 /3 检出。所有文件先读全、核摘要及模式，再创建私有留存。迟到的内容审查与当前原件核验分开；删除原件后，留存内容仍可核验，而当前原件不能变成可用。

程序只承担内容身份与参数绑定。完整编译器/阶段/SDK 来源、/6 真实接入、symbols.o 生成来源和两个完整产物的字节、调试与签名相等仍需实现并验证。私有测试与生成通过不会使这些项目自动通过。工程本体规定含义 → ggen 生成合同 → Rust 执行核验 → RRSI 保存失败及对新候选的实际反馈。
