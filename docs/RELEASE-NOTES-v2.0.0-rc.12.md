# OntologyEngineering v2.0.0-rc.12 — 视图组成与制图规则本体

**读图说得清每个视图由什么组成；制图规则写成本体里的形状约束，逐条带国标条款和把握程度，报出图纸偏离，确定的偏离给出改正后的图纸。**

这是 v2.0.0 的第 12 个整合候选（预发布，重构中）。rc.11 之后，我们用四张没见过的图纸（两张由 CAXA 绘制）和两张开发图纸，按一位资深制图专家的逐条意见，做了五轮：读新图、按意见纠正、规则本体化、形式化、视图组成。

## 这一版有什么

| 内容 | 位置 |
|---|---|
| **视图组成**：“一个视图由什么组成”成为正式结构。组成包括视图自己的线、名称和比例、剖切符号、投射箭头和字母、放大部位的圈和引出线，画在别的视图上的也归到它所属的视图；尺寸、公差、粗糙度、基准、注写、指引线、标题栏只算“位于”其中。检查页的“视图”分类按组成显示，另有开关叠加位于其中的标注 | `crates/oe-drawing/src/view_composition.rs`、`view_component_roles.rs`、`view_mark_targets.rs`、`crates/oe-drawing/assets/view-composition.js` |
| **制图规则本体**：45 条制图规则写成导出事实上的 SHACL 形状，每条带概念编号、国标条款、把握程度（确定、可能、要问专家），例外也写在形状里；来源、识别、呈现三层分别报。新增七条视图标注规则（剖视图和断面图的名称、剖切位置、投射方向和字母，局部放大图的标注，向视图和局部视图的名称、箭头与字母） | `crates/oe-drawing-check/knowledge/drafting-ontology.toml`、`crates/oe-drawing-check/src/drafting*.rs` |
| **图纸偏离与改正**：偏离清单逐条写规则、条款、位置和视图；重合类条目指到圆和圆弧上的具体区间，越界条目指出越出的那一段。确定的偏离生成改正后的 DXF（新文件，原图不动），检查页左右对照；同一图号的两版图纸列出差别 | `crates/oe-drawing/src/drafting_issues.rs`、`correction.rs`、`route_correction.rs`、`revisions.rs`、[图纸的版本与改正](DRAWING-REVISIONS-CORRECTIONS.md) |
| **识别知识**：识别知识卡从 21 张增加到 53 张，逐概念覆盖从 136 个概念增加到 172 个。新增断面与局部剖视、螺纹规定画法、块里的注写、散画的剖面线区域、不打印图层，以及未解释图元按标注组成重判 | `crates/oe-drawing/knowledge/`、`crates/oe-drawing/src/` |
| **正式字段**：剖切与断面的证据、视图的位置角色与表示法、视图标注指向哪个视图、成员是“组成”还是“只位于”，都由合同字段表达，由锁定的生成器生成 | `specs/modules/drawing-understanding.toml`、`generated/` |
| **生成时限**：生成工具的时限从带版本的资源取（300 秒），实际用时记进回执，超时会终止整个进程树 | `crates/oe-design/src/generation.rs`、`crates/oe-core/src/process.rs` |
| **转换器锁定**：CADCraft `cadcraft-cli 0.15.1-aixcam.9 (dev)`，fork `fix/svg-member-identity` 提交 `09fcf70`。嵌套在块参照或尺寸里的图元，画出的 SVG 组带上 `data-member`，写出从顶层图元到它的句柄链 | `integrations/runtime-locks/cadcraft-source.json` |

**升级后要按锁重新构建 cadcraft-cli，并写新的运行记录。** aixcam.8 及以前的运行记录会被路线拒绝。构建时请直接用 1.95.0 工具链自带的 cargo 和 rustc（见 rc.11 发布说明）。

## 效果

在六张图纸上（都不随仓库分发）：

- **视图：** 35 个视图都读出了组成。只勾一个视图时，检查页画出的图元和关系图里的组成逐项相同。
- **未解释：** 四张新图里没读懂的图元，从最初读时的 533 个降到 14 个。两张开发图纸各剩 1 个。
- **规则：** 45 条规则在六张图上的命中分别为 95、156、185、341、74、62 条。偏离清单分别为 32、44、57、248、27、22 条，每条带条款和把握程度。
- **改正：** 一张图生成了改正后的 DXF。
- **复现：** 两遍读图逐字节相同。
- **局限：** 这六张图都用来发现和修正问题，结果不说明能用到别的图上。专家对本版结果的复核意见留到下一版处理，见已知限制。

## 已知限制

- **不是工程采用：** 识别结果是待复核的候选。
- **专家对本版的意见留到下一版：**
  - 叠在一起的形位公差框，框线被两个公差同时算上；
  - 标准件螺钉在螺孔里的螺纹画法偏离没有报出；
  - “剖面线应画到螺纹粗实线”这条规则还没有；
  - 检查页“完整结构”默认藏掉局部剖，应当照原图显示；
  - 画在不打印图层上的可见轮廓应当报为偏离。
- **视图组成不完整：** 有的视图里有画出来、但和视图关系未定的线（没读懂的线、不打印图层上的线、图库调出的标准件），它们不随视图显示。
- **规则引擎容量：** 最大的一张图导出的事实约 8 万条，接近共用 SHACL 引擎上限 10 万的八成。
- **测试：**
  - 在 macOS 上，`cargo test -p oe-drawing` 里有一项改正文件的测试，用默认临时目录时会失败：默认临时目录经过 `/var` 符号链接，而程序打开目录时不跟随符号链接。把 `TMPDIR` 设到不含符号链接的目录后通过。下一版修正测试。
  - oe-cli 有 10 项测试依赖本机环境（凭据、书目原件、模型库），oe-design 有 1 项夹具测试在第三方库里失败。这些都不在发布复核的十组测试里。
- **其他：** [rc.11 发布说明](RELEASE-NOTES-v2.0.0-rc.11.md)列出的已知限制仍然有效。

## 安装与升级

```sh
cd "$HOME/OntologyEngineering"
git fetch --tags && git checkout v2.0.0-rc.12
sh scripts/install.sh
"$HOME/OntologyEngineering/var/install/bin/oev2" --root "$HOME/OntologyEngineering" --version
```

- 安装器保留上一安装为 `var/install-previous.*`，私有数据目录 `var/` 与 `sources/` 不受影响。
- 已有工作区无需迁移。
- 已打开的会话要重新打开，才会加载新版技能和 MCP 服务。
- 读图前，按 `integrations/runtime-locks/cadcraft-source.json` 构建 cadcraft-cli，并写运行记录（见[读懂已有工程图纸](DRAWING-UNDERSTANDING.md)）。

本版不授予工程采用，项目的全部根验收仍按各自证据判断。
