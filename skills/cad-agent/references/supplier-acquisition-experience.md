# 供应商资料取得：经验查阅入口

用于标准件模型、图纸、规格资料的取得与异常诊断。先按当前问题找到条目，再读对应
操作指南；型号、文件名或旧产品目录不是主要匹配条件。此表是已维护的操作参考索引，
不声明 Semantica 活动记忆已激活，也不赋予浏览器、采购或 CAD 操作权限。

主 agent 将适用条目的**实际正文**及当前不满足的条件交给 Jev；项目记录保留本文件
哈希、条目 ID 和选择结果。若当前条件未观察到，只把经验用于安排检查，不补成已满足。
选择章节时也需提供行为、适用及排除条件，不能仅给标题；误选应保留并由主 agent 复核。

## SUP-IDENTITY：确认会话与配置

遇到“已经登录但不能生成”，先区分账号、完整型号、生成服务和文件下载四处的状态。
Chrome 资料名、网站用户名、邮箱可能不同，按正常账户页面的完整字段核对指定身份；
整页出现用户名片段不能证明。没有完成型号参数也不能诊断为登录失效。
优先利用有效会话；失效后按实际正常登录界面恢复。历史人工准备不是未来必须要求用户
登录的步骤，也不证明已实现自动重新认证。见 [MISUMI 会话预检](misumi-cn-guide.md#会话预检与登录恢复)。

## SUP-PURPOSE：选择满足具体用途的资料

向 Jev 提供当前需要的几何、二维编辑、尺寸公差、材料/性能或采购证据，以及页面实际
选项。模型建议仍需核对明确要求：若要求与人工 STEP 同格式对照，另一个可导入 NX 的
格式即使下载成功也没有完成对照；先复核选择再执行。3D 模型不能补全规格，二维文件
也未必带公差。见 [按用途选择](misumi-cn-guide.md#按工程用途交给-jev-选择资料)。
当几何已有足够证据、缺的是采购资料时，下一项应是完整订货号、每包数量、采购数量
及对应日期/条件的报价或供货资料；重复下载模型不能补这个缺口。采购包数量与装配
实例数分列，查阅资料不等于下单。这项取自既有供应商指南，不是本次三份下载证明了供货。

## SUP-GENERATION：不确定执行与失败范围

生成动作已派发、读回却失败时，保留“已执行、结果待查”，检查原作业与新文件。
同次生成超时、结果不明或生成服务失败时，不靠换格式重新生成。独立的规格/目录查阅
可以继续，恢复生成须有新的实际依据。账号可用与下载子站出错可以同时成立；浏览器
资源时间记录的状态 0 不能独自证明 HTTP 403 或 CORS，公开根页拒绝也不证明生成请求
的状态。见 [用途选择与反馈](misumi-cn-guide.md#按工程用途交给-jev-选择资料)。

## SUP-FILE：文件身份与验收范围

核本轮新文件、来源和完整型号，再检查归档/内容/哈希。带时间戳的 ZIP、`.step`、AP214
或单零件名后缀可能有效；不能因不符合旧 AP203 文件名约定就判断网站不支持。
内容签名和 CRC 不证明单位、几何、尺寸或机械适用性。原生格式继续相应阅读器检查；
只有当前需求已被带证据的接受记录覆盖，才能结束该资料子任务。
见 [MISUMI 指南](misumi-cn-guide.md)、[NX 执行](nx-execution.md)。

## SUP-SCOPE：验证结果只覆盖被测条件

一个人工准备好的普通会话取得多个产品，不等于多个无人值守冷启动或失效后自动登录。
新增替代产品不能覆盖原失败型号；启动、账号、选型、生成、落盘、退出和人工介入分别
记录。只在下载阶段观察到零焦点切换，不代表整个启动至退出过程符合不干扰要求。
没有同时隔离模式、重启和会话准备，不能把恢复归因给其中一个条件。
见 [冷启动实测边界](misumi-cn-guide.md#macos-冷启动与不同-cad-界面的实测边界)。
