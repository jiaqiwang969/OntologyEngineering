# 合成决策复盘：定位检测座

此例全新编写，金额为任意成本单位。不是客户案例、加工参数或已执行试验；也不是报告生成器的第五份 JSON 输入。按顺序读每轮，再使用 [评审卡](../../templates/decision-review-cards.md) 写出当前决定。

## 第一轮：类似零件，但保证方式不同

询问是定位检测座，可调用现有加工设备。客户说“装上后读数必须重复，记录要能查到”；制造方习惯只查出厂尺寸。设备资料显示带自动找正功能，但未提供找正误差、当前配置或数据导出样例。客户尚未给重复性判据。

此时应把尺寸、装夹后的重复性和记录追溯分开。问客户检测座怎样安装、重复性如何验收；制造方提出装夹与测量方案；向供方核找正范围和记录导出。不因相似结构取消尺寸控制，也不由自动找正推断产品无需定位精度。

## 第二轮：看平均单价会选错

客户拟要甲型 24 件、乙型 16 件，同版同范围比价；设备可调配已确定。假定能力条件成立，所有未列费用在两配置中相同。甲型已安排自制，共用准备已完成且不能退回，乙型利用同一底座仍需专用定位件。

| 输入 | 数值 | 范围 |
| --- | --- | --- |
| 已发生共同准备 | 900 | 甲乙共用，不因乙型外协取消 |
| 乙型重复制造 | 48/件 | 含人工、运行和同范围检验 |
| 乙型新增定位件 | 160 | 乙型自制才发生 |
| 乙型外协 | 62/件 | 同范围到厂，不另收最低费或交接费 |
| 会计分摊给乙型的共同准备 | 360 | 解释成本用，已经包含在 900 中 |

平均分摊乙型自制单价为 `(16×48+160+360)/16 = 80.50`，高于外协的 62。但本次选择的增量是自制 `16×48+160 = 928`，外协 `16×62 = 992`，自制仅少 64。

这支持在已声明条件下暂留自制；差额很小，应核实专用定位件和制造用时。如果乙型单独启动且共同准备尚未发生，费用就变为 `900+160+16×48 = 1828`，该情景下外协更低。平均分摊、追加订单、独立订单不能共用一个选择结论。

## 第三轮：更详细不等于更便宜

后续确认乙型必须增加一道测量及记录，每件增加 7；原重复费用不含该项。外协已包含同项测量，其他条件不变。共同准备仍不受影响。

| 预算变化 | 金额 |
| --- | --- |
| 原乙型自制增量 | 928 |
| 新覆盖费用，16×7 | +112 |
| 新自制增量 | 1040 |
| 外协同范围总额 | 992 |

路线翻转为外协少 48。这是验收范围补齐后的预算变化，不是人工涨价，也不是现场已经省了 48。若随后出现外协最低收费、不同版次或能力缺口，还要重开。

## 第四轮：试验与反馈能说明多少

现场在同一座上量了 6 个位置，都合格。它证明这些位置在当次条件下的结果，不能称作 6 件独立首件，更不能估计整批能力。若要比较两种装夹方案，应说明独立试件、重复装夹、位置/顺序、仪器和操作者影响；本轮不足时只报告探索结果。

后来中间联系人承认，前述重复性数值是他建议的，尚未得到设计责任方确认。应退回该要求及依赖它的验收、费用和路线结论，保留条件分支；已完成的测量仍是原条件下的观察，不用删除。行业资料认为数值合理，也不替代客户确认。

复盘重点是：每个新事实究竟改变了哪个决定、金额和适用范围；原始记录、旧结果、预算情景和实际采用始终分开。
