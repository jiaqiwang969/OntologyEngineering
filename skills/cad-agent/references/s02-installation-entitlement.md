# S02 installation and entitlement memory

## Source-grounded interpretation

S02 is installation onboarding, not CAD modeling. The 2023 source teaches nine steps: route and region, offering comparison, trial, personal-use choice, account creation and terms, sign-in, account download, install and application sign-in, and team setup.

The installer, application sign-in, and team setup are narration-only. The source cannot support an OS-specific installation script.

## Operational rule

1. Detect whether a suitable Fusion instance is already operational.
2. Preserve dated tutorial steps as source evidence.
3. Reacquire current Autodesk eligibility, registration, trial, system-requirement, installer, and terms evidence before an action.
4. Stop at user gates for credentials, legal consent, entitlement selection, billing, and team or hub mutation.
5. Do not reinstall an operational instance merely to reproduce an onboarding video.
6. If installation is required, establish official installer provenance, supported OS, document protection, rollback, and post-install smoke checks before mutation.
7. Never infer entitlement, expiration, or team membership from launch success.
8. A team/hub precondition can be verified with an already-accepted read-only hub query (fusion_mcp_read queryType=projects), which proves a usable project context exists without entering the UI.

## Source-to-current boundary

The source shows a 2023 comparison page, price, referral program, and qualification wording. These are historical facts. The current evidence snapshot retrieved on 2026-07-21 indicates that Personal Use remains intended for qualifying non-commercial personal and home-based work, begins with a limited-versus-commercial boundary, and is governed by current account and renewal procedures.

The video's less-than-USD-1000 description claim is not promoted as current policy because the current official pages consulted in this cycle did not restate it. Recheck official terms instead of filling that gap from memory.

## Human authorization gates

- Identity and credentials
- Acceptance of terms or privacy statements
- Entitlement or subscription choice
- Billing action
- Installer execution or repair
- Team or hub creation, join, or change

## Evaluation boundary

S02 may advance the curriculum but does not prove production readiness. Semantic release and production activation remain separately gated.
