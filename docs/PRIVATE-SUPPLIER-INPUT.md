# 供应商身份输入与核验回执

supplier读取用户显式提供的身份匹配字段，通过正常账号页面核对；不会读取浏览器Cookie、密码或个人资料目录。输入值只在内存比较，回执记录匹配结果与来源摘要，不证明密码重新认证或未来登录状态。

身份文件及已生成的核验回执均按私有文件准入。Unix保留禁止组/其他用户访问的要求。Windows通过原生API核owner、DACL及实际文件身份：当前进程用户、SYSTEM和Administrators属于明确可信主体；其他主体的有效allow、未知owner、缺失/null DACL、未支持的object/callback ACE拒绝。此范围不防御已被信任的系统管理员。仅供子对象继承的条目不授予当前常规文件权限；目录不能作为身份输入。

Windows读取时固定父目录与叶文件，拒绝reparse和硬链接，核有界内容、物理文件及权限前后身份；页面观察后再次复核。内容相同但文件被替换、权限在观察期间变化，也不能保留account_verified。回执仍须符合原schema、同一浏览器会话、时效和当前来源，私有权限通过不替代这些要求。

程序只检查、不静默修改用户文件权限。拒绝后由agent定位输入、来源或权限缺项，不退回旧cad-agent、不取消检查取得通过。合成页面测试、真实官网会话核验、下载和工程适用分别留证。旧schema名称保留原身份，当前执行由v2 Rust承担。
