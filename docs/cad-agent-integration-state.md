## 统一职责与交接

根入口组织需求、对象及版本、当前决定、条件和缺口；Jev 共用工程方法与既有设计
模式，辅助路由、资料筛选及核查建议。供应商资料通过统一
[知识入口](../references/supplier-knowledge.md)读取，按需恢复原页，保留工艺条件、
反例、图示定位和来源身份。候选资料经过适用性核对后才写回项目采用记录。

CAD 负责原生几何、接口、装配状态与回读证据；制造模块接续工艺、检验、成本与交期。
`cad_process_handoff.py` 核对来源 SHA、原生回读位置、模型来源摘要和对象依赖，
保留 CAD→工艺与工艺→CAD 的问题及变化影响。来源投影不替代正式工程裁定。

source-locked Semantica 是唯一正式语义执行者。CAD 通过根控制面传递任务，
不保留第二套本体引擎。`runtime/cad-operational-source-lock.json` 仅锁定非语义
执行代码，不豁免语义后端检查，也不授予任何项目发布权限。
