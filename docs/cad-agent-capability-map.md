# CAD Agent 能力与公开边界

CAD Agent 是工程本体论下的通用 CAD 模块，焊接只是一个使用案例。它对所有工作先统一产品配置、状态、对象身份、来源、几何/关系证据、主张和反例；再按任务调用零件、图纸/BOM、装配、机构或制造专项工具。正式语义仍只由 Semantica 执行。

| 能力 | 通用方法与证据合同 | 本公开便携包的可执行范围 |
| --- | --- | --- |
| 零件设计、修复、导入与回读 | 定义、参数、特征、基准、尺寸来源、模型版次和保存后回读 | Fusion 本机守卫调用；其他 CAD 的经核验回读可导入 |
| 图纸、尺寸、公差与 BOM | 图纸权威、标注、定义/实例数量、来源和不一致问题 | 通用证据合同可记录；未附带 NX/AutoCAD 绘图与远程操作桥 |
| 装配 | 实例身份、世界坐标、配合、界面、紧固件、工具空间、顺序和状态 | 通用证据合同可记录；完整装配重建、路径/接触求解和影片工具未随公开包交付 |
| 机构 | 运动拓扑、运动副、轨迹、极限位、运动包络和载荷边界 | 通用证据合同可记录；专项机构求解器未随公开包交付 |
| CAD 与制造协同 | 同版对象到功能、工艺操作、检验、成本、交期的双向引用和变更影响 | 来源校验、项目 ABox 投影、双向问题与依赖影响可执行 |

公开便携包的“可记录”不是声称已自动完成建模或验证。接收方可按同一证据合同接入自有 CAD、装配和机构工具，但必须另行记录实际工具调用、模型保存与回读、求解范围和实物验证。私有历史案例、客户资料、现场配置和未审执行桥不因方法通用而自动成为公共资产。
