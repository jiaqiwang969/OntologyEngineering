# 从中间模型识别核心控制参数

用于从照片、视频、稀疏观测或粗糙网格重构形状，尤其是反复修改仍有同一种结构偏差、尚不清楚截面如何变化或曲面如何生成时。已有明确尺寸和生成关系的普通建模可直接执行，不必增加图生模型步骤。

目标是找出能解释观测、可预测修改结果的**控制变量、生成关系与约束**。生成关系可以是解析式、样条、特征依赖或程序，不要求所有对象都有闭式公式。

## 先区分模型类别与参数值

把重构写成两个可检查的关系：

```text
几何 G = F_m(θ; C)
预测图像 Î = Render(G, 相机, 材质, 光照)
```

`m` 是生成模型类别，`θ` 是独立控制参数，`C` 是约束和派生关系。相机、材质和光照也影响图像，但与几何参数分开记录。

先问当前模型能否表达观察到的变化。例如，平面轮廓等厚拉伸无法表达峰顶在截面内迁移；提高网格密度或调波幅不能补上这个自由度。若多个合理参数组合都留下同一种系统偏差，先排查相机与测量方式，再重新考虑模型类别或缺失关系。

参数少本身不是目标。保留足以解释关键特征的自由度，避免把每个顶点坐标都当成独立设计意图。

## 中间模型的作用：让空间假设可以被检查

```text
原始证据 → 可检查的空间假设 → 截面/测量/干预
        → 控制变量及生成关系 → 可重建模型 → 原始证据校准
```

根据尚未解决的问题选择桥梁：

| 尚不清楚什么 | 有用的中间表示 | 要从中读取什么 |
|---|---|---|
| 前后关系、凹凸、连续曲面走向 | 图生网格或粗略三维模型 | 候选拓扑、截面、峰谷轨迹、深度变化 |
| 哪种截面或特征关系能够产生外形 | 少量截面、简化 CAD、程序曲面 | 哪些自由度必需，哪些量应当耦合 |
| 实际尺寸或空间位置 | 有尺度的扫描或多视图测量 | 测量值、配准关系及其误差 |

记录来源、坐标系、尺度状态以及模型被补全或裁切的部分。用户提供的图生 STL 可以立即作为分析对象，但其背面、厚度和局部凹凸仍属于候选解释。它增加的是先验和可操作性，没有增加原物的独立测量。

先旋转、切片、取等高线或比较重复部位；明确一次操作要区分哪两个假设。只有需要时才精细拟合中间网格。判断桥梁是否有用，看它是否暴露了关键关系，而非只看它是否逼真。提取关系后，可以替换或丢弃桥梁，不必继承其误差。

## 把观察压缩成可控的生成关系

分开记录三类信息：原始证据中的可见特征、中间模型中的测量、为设计加入的假设。照片亮线未必是几何最高线；图生模型中的恒定厚度也未必是原物的恒定厚度。

为候选控制量记录含义、单位或归一化尺度、合法范围，以及独立量或派生量身份。例如截面宽度、峰顶位置、截面高度、相位和圆润程度可能需要分别控制，也可能由同一关系驱动。依据当前证据决定，不照搬案例参数表。

把依赖显式写出：改变一个独立量后，哪些导线、截面或特征随之改变，哪些量保持不变。周期、对称、边界、孔洞、厚度和连续性都可以减少自由度，但必须有设计意图或证据支持。不能只因加了约束更容易拟合，就宣称它是原物的规律。

## 用干预验证参数是否抓对了

对有争议的关系做小而有区分力的实验：

1. 在修改前写出预测：改变哪个参数，会让哪个可见特征向哪里变化，哪些特征应保持不变。
2. 在合法范围内改变一个独立量，或一个必须联动的参数组；保留基准，并固定其他条件。
3. 比较相同坐标系下的截面、导线、轮廓或固定视角渲染，记录实际响应。
4. 若响应不符合预测，修正参数含义、依赖关系或模型类别；若方向正确但幅度不对，再调参数值。

“改参数能产生预期变化”验证了模型内部的控制关系。再与原始证据比较，才检验这套关系是否解释了对象。二者都不等于证明原物的真实制造过程；“可以由某种切割生成”与“原件确实如此加工”需要不同证据。

若两个参数在现有视角下产生几乎相同的效果，它们尚不能分别辨识。可用有依据的约束固定其中一个，保留多个候选，或在尺寸/加工决策确实依赖它时补充视角或测量。不要用更多小数位掩盖这种不确定性。

## 为什么能重新回到原图比较

建立生成模型以后，原图成为检验参数及关系的依据：每次修改有可预测的图像后果。原图始终可以用；改变的是我们已能把偏差关联到具体控制量。

- 先对齐物体坐标、尺度和相机。透视造成的差异不能直接当成物体不对称；不要用逐区域图像变形把几何误差消掉。
- 先比外轮廓、内轮廓、可靠特征位置，再比截面走向和高光变化，随后调材质。比较几何版本时固定相机、材质和光照；必要时交替校准，并说明这一轮改变了哪类量。
- 同时保留无纹理诊断图与材质效果图。木纹、高光和阴影可能模拟或遮住曲率问题。由照片提取的颜色与粗糙度是外观估计，不是实测材料属性。
- 把轮廓误差、曲线误差、网格距离和图像观感分别报告，写清坐标系、归一化尺度及比较对象。对桥梁网格的拟合分数不能称为对实物的精度。
- 数据允许时，留出部分视角、截面或重复部位用于检验。对同一图生网格留出样本，只能检验对该网格的概括能力，不能增加对实物的独立证据。

## 对称性如何参与修正

当用户明确要求对称或证据支持重复规律时，让对应部位共同约束同一生成关系。不要只复制一个尚未拟合好的局部；这样会把偏差也复制到所有位置。先拟合共享规律，再生成对应部位，最后检查导出几何。

区分几何对称与材质对称，自然纹理通常不需要镜像。还要说明约束在哪个空间成立：归一化空间中的旋转对称，经非等比拉伸后不一定仍是成品中的旋转对称。

## 留下什么才可复用

保留能重建结果的参数及关系、决定模型类别的关键实验、与原始证据的对比、仍未确定的自由度。几何有效性与形状吻合分别检查；导出后重新读取适用的连通性、孔洞、方向、对称或尺寸约束。视觉接受不能替代物理尺度或加工验证。

可在项目现有记录中使用这个简短实验格式，无需另建流程系统：

```text
问题与证据：观察到什么；来源/版本；什么仍未知
桥梁用途：要区分什么假设；来源、坐标和尺度
候选关系：模型类别；独立参数 → 派生量；约束及其依据
干预预测：参数从 A 到 B；预期变化；保持不变的条件
实际结果：截面/导线/图像对比；是否支持；下一次修正
原始证据校准：吻合处、残差、未辨识量；当前结果版本
```

继续生成时使用 [computational-geometry.md](computational-geometry.md) 选择合适的几何实现。需要了解本方法从何而来，阅读[木镜框案例](wave-frame-parameter-discovery-case.md)；案例中的八瓣、特定截面和数值均不是通用要求。
