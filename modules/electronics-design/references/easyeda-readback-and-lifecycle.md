# 属性、双侧网表和任务服务生命周期

## 属性的层次

区分原始 COMPONENT 实例差量、工程器件/封装默认值、加载后的有效属性和 getter 快照。
原始记录缺键可能有多种解释；查当前对象实际引用的工程库及版本，不能直接认定丢值、
自动补值或用同型号另一 UUID 替代。字符串、数值、布尔值保留类型。

核当前状态应重新取得对象；旧对象 getter 可能只反映取得时的快照。使用本机实际动作目录
支持的属性读取参数，不假定私人修改版的开关已进入上游。记录“未请求”“getter未提供”
“提供空字典”“提供有值字典”“读取失败/格式不支持”的区别，不能统一改成 {}。

属性读取前后核 Project、PCB、文档/tab、对象和版本。顺序观察并非原子身份锁，无法排除
两次观察间切走再切回时就保留限制。跨图用实际 uniqueId 与引脚/焊盘映射，不要求两侧
primitiveId 相同。位号传递通过不自动证明 Value 或其他字段传递通过。

## 三种网络原件

SCH 网表记录原理图逻辑连接；PCB 原生网表记录本板导出覆盖的器件属性和焊盘网络；
DSN 是路由交换资料，其覆盖由实际导出器决定。各自保存原始字节、SHA、采集时间与对象身份。
请求了某种格式不证明输出符合该 schema；失败、空文件或身份漂移不能换用另一侧网表补成功。

pin→net 一致不证明铜连通、间距、制造或物理功能。原生导出、原文档重开、便携文件导入
独立新工程后重开各自验收，不能互相替代。

## 服务归属与停止

使用已经核准且属于本任务的有限服务；启动前核依赖和端口归属，显式保存 owner/PID/版本。
仅连接诊断不应隐式创建长期后台服务。本次安装和离线检查不启动 daemon；
锁定 0.25.1 的 daemon start 会尝试替换同端口旧 daemon，且默认更新 Skill；真正 EDA 任务需要启动时须先核端口归属、使用 --auto-update-skill=false，并按当前授权执行，并在结束后核归属清退。

普通连接、强制重连与热替换的行为依版本核准；菜单显示 Connected 仍需结合当前 health
和目标只读响应。不要在用户工作中反复强制重连。停止/超时不等于取消或回滚已接受的 SDK
动作；存在 pending 写入时先核实际执行状态，不能交错启动新 owner 写入。

正常退出、明确期限结束和随机掉线分开。新任务按新授权启动，不为减少点击添加自动复活、
自启或长期常驻。连接稳定、源码测试、安装包身份与具体工程成功分别记录。
