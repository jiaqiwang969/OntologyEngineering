3. Freedom-from-interference claim register
-------------------------------------------

claim_id: FFI-EPS-SW-001
claim: A fault in one monitoring unit does not corrupt the other unit or the
       degradation decision beyond the allocated safety requirement.
claim_status: Open
source_anchor: Part 6 7.4.9

interference channels to analyse:
  - execution time and scheduling
  - shared memory and data corruption
  - communication ordering and stale data
  - shared peripheral and driver state
  - error handling and control-flow coupling

candidate evidence only:
  - memory and task partition configuration
  - worst-case execution-time and scheduling analysis
  - interface protection and data-integrity tests
  - fault-injection results
  - dependent-failure analysis

No evidence above is present in this teaching draft. Separate units and a tree
diagram do not prove freedom from interference.
