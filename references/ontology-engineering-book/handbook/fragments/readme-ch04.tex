
\section{本章内容}

本章介绍工程本体论中常用的描述语言和工具，包括：
\begin{itemize}
\item RDF (Resource Description Framework) 及其序列化格式
\item RDFS (RDF Schema)
\item OWL (Web Ontology Language)
\item SPARQL 查询语言
\item Protégé 本体编辑器
\end{itemize}

\section{Protégé快速入门}

\begin{enumerate}
\item 安装插件：Tools \(\rightarrow\) Plugins，安装 OntoGraf（可视化）、SWRL Tab（规则）、SPARQL Query（查询）
\item 新建本体：File \(\rightarrow\) New，在 Active Ontology 视图设置 IRI
\item 导入本体：Active Ontology \(\rightarrow\) Ontology imports，输入IRI或本地文件
\end{enumerate}
