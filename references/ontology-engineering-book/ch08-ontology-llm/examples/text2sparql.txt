# Text2SPARQL：自然语言到查询语言的安全转换
# Text2SPARQL: Safe Natural Language to Query Translation
#
# 让LLM"写查询"而不是"答事实"——事实只能来自查询结果

# ==============================
# 1. 三种技术路线
# ==============================
# 路线A 模板槽填充：
#   预定义查询模板，LLM只负责识别意图与填槽
#   高可控、零注入风险；覆盖面有限
# 路线B LLM直接生成SPARQL + 校验层：
#   灵活覆盖长尾问题；必须配校验层（见第3节）
# 路线C 语义解析（训练专用模型）：
#   精度高；需要标注数据，迭代成本高
# 工程组合：高频问题走A，长尾走B，A/B共享同一校验层

# ==============================
# 2. 路线A示例：模板槽填充
# ==============================
# 模板T01 设备状态查询：
#   意图关键词：状态/在干嘛/空闲吗
#   模板：
#     SELECT ?status WHERE { {EQUIPMENT} mfg:hasStatus ?status }
#   槽位：{EQUIPMENT} ← 实体链接结果（别名表见第7章）

# 模板T02 能力查询：
#   "哪些设备能加工{MATERIAL}？"
#     SELECT ?e WHERE {
#         ?e rdf:type/rdfs:subClassOf* mfg:Equipment ;
#            mfg:canProcess {MATERIAL} . }

# 填槽过程：
#   "3号车床现在空闲吗" → 意图T01 + 实体mfg:Lathe_003
#   → SELECT ?status WHERE { mfg:Lathe_003 mfg:hasStatus ?status }
#   → 返回 mfg:Idle → 生成回答"是，当前空闲"

# ==============================
# 3. 路线B的校验层（关键防线）
# ==============================
# LLM生成的SPARQL必须依次通过四道检查：

# (1) 语法校验
#     用SPARQL解析器（Jena ARQ / rdflib）解析，失败→重试或回退模板

# (2) 操作白名单（防注入/防破坏）
#     只允许 SELECT / ASK；
#     拒绝 INSERT / DELETE / DROP / LOAD / SERVICE（防外联）
#     生产端点同时在服务端禁用update（双保险）

# (3) Schema校验（防"词汇幻觉"）
#     查询中出现的类/属性必须存在于本体：
#       LLM编造 mfg:hasMaxSpeed（本体中只有 mfg:hasSpindleSpeed）
#       → Schema校验失败 → 把本体属性清单回喂LLM重新生成
#     这是Text2SPARQL最常见错误，校验后准确率提升显著

# (4) 资源限额
#     强制 LIMIT（如1000）、查询超时（如5s）、禁用笛卡尔积形态

# ==============================
# 4. 提示词要点（路线B）
# ==============================
# 提供给LLM的上下文应包含：
#   本体Schema摘要：类层次 + 属性清单（域/值域）+ 3~5个示例查询
#   明确规则："只用清单中的词汇；不确定就返回 NEED_CLARIFY"
# 示例few-shot（一问一查询），覆盖：单实体查询/过滤/聚合/路径

# ==============================
# 5. 失败回退策略
# ==============================
# 生成失败/校验不过 → 重试（带错误信息）最多2次
#   → 仍失败 → 回退模板匹配
#   → 模板也无 → 澄清式反问用户（"您是想查状态还是维护记录？"）
# 禁止：在任何失败分支让LLM"凭印象"直接回答事实

# ==============================
# 6. 评测指标
# ==============================
# 语法正确率：可解析的比例（基线，通常很高）
# Schema命中率：词汇全部在本体内的比例（核心质量指标）
# 执行准确率：查询结果与标准答案一致的比例（最终指标）
# 评测集：把第3章CQ清单转成"自然语言问法→标准查询"对，一举两用
