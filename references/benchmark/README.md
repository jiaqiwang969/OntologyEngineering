# 千题闭卷评测（ISO 26262 · 双金标准）

对本 skill 做的 1000 题闭卷测评：答题方唯一知识来源是本 skill
（两卷书 + 刻录层 + 检索脚本），先验知识只许组织语言、不得供事实。

## 评价标准（双金标准）

每题两个分项，另设诚实项：

| 指标 | 判什么 | 判法 |
|---|---|---|
| **事实分** | ISO 实质是否正确 | 金标准关键词组 any_of 命中（方法表符号题取答案首个符号 token 严格比对） |
| **讲例分** | 是否用书中案例/人物/命题讲出来（本书的核心价值） | 案例锚点词 any_of 命中；仅教学类考察，干对照组不计 |
| **陷阱诚实** | 对 skill 未覆盖内容是否承认"查不到" | 40 道未标注陷阱混入各批；承认类关键词命中即过，臆答即败 |

## 隔离协议与审计

金标准全程不进 skill 目录；题目文件不含答案；答题 agent 明令禁读评测目录
其他文件。赛后机械审计：九个答题 agent 的完整工具调用记录 grep 金标准
文件路径，命中全部为零；且方法表金标准（仓库 RDF）物理上不在 skill 内。
行为学证据：一道被误设为陷阱的真题（词条 1-3.180/181）被答题方按词条卡
如实答"对"——与陷阱金标准相反、与事实相符，自证未接触金标准。

## 迭代吸收记录（评测的真正目的）

千题评测挖出的病灶与本体级修复（2026-08-16 迭代轮）：

| 病灶 | 修复 | 复测验证 |
|---|---|---|
| 词条卡不携带案例（讲例率 68%） | 教学案例层：25 个场景一等对象 + `taughtBy` 对象属性边，由加权关键词交集在刻录时**计算**（非人工映射），134/153 自动连接，低信号词条走"词条→章→案例"兜底遍历 | 上轮讲例 0/30 的最难切片 → 程序依从 30/30（严格旧金标 11/30，经甄别 19 例为金标准眼盲，真未讲例 0） |
| 出题人不知词表边界（trap-1004 自摆乌龙） | `CoverageDeclaration`：显式声明收录范围，界外判缺以声明为据（书中 ch11 局部完整性纪律反哺 skill 自身） | 覆盖声明已入卡片头部 |
| 近义命题误引 + 跨行检索失配 | 全书命题总索引 97 条单行化（命题+出处） | 逐字可检索、近义可区分 |
| 判据本身过时（金标准不识新讲法） | bank v1.1：案例金标准并入注册表签名锚点，变更留痕版本化——判据随本体演化 | 本文件即留痕 |

结论：本评测体系的产出不是通过率，是上表。每轮评测 → 病灶 → 本体修复 →
复测归因，构成 skill 的持续演化回路。
