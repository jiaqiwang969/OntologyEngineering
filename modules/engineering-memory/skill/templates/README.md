# Agent-maintained templates

These files are structural starting points, not valid evidence or authorization.
Replace every placeholder using actual source bytes and current task state.
An experience requires nonempty verified sources and a source-bound timeline;
the empty arrays in the template intentionally cannot pass record validation.

Use `evidence` to obtain complete SourceAnchor values. Do not calculate offsets
from a search row number or invent a digest. Set Project bindings from the actual
Project file and its bytes. A null Project is only appropriate for an explicitly
unbound task; it never grants engineering adoption.

Save filled templates in a private data directory. Do not commit sessions,
experience contents, client policy paths, or personal project data.
