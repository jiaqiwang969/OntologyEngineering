# 合成练习：一句批次答复怎样改变成本估算

全部对象、资料及金额为重新设计的教学数据，单位为任意成本单位。演示参数依据、批次计费和条件区间；没有真实客户、报价承诺或制造实绩。本练习是 Markdown 手工分析，不是报告生成器输入。

## 第一轮：已有资料

同一版本普通安装块共30件，客户要求先交6件、再交24件。比较的质量、表面状态、包装和交付范围相同。订单尚未开工；本例按30件投入均合格的基准情景核算，返工、损耗和实际能力尚未验证。以下金额已统一为同一币种未税口径。

| 来源 | 原始内容 | 依据性质与范围 |
| --- | --- | --- |
| S-M | 原材料每投入件20 | 匹配本版及本次数量的书面价格 |
| S-J | 通用装夹准备450，配套重复加工每件50–58；专用快换装夹准备950，配套每件35–42 | 技术预算，包含各路线本例所列准备及验证工作；两个范围是工程估计，非实测或概率分布 |
| S-T | 表面服务每件8，每处理批最低300；每次运输60 | 对象匹配的供方报价；允许的处理批安排尚未答复 |
| S-O | 整件外协每件110，含材料、加工、表面服务和供方责任范围内检验；两次运输各60 | 该数量及两次交付范围的书面价格；本例不另有最低收费 |
| S-P | 最终包装及交付侧验收按同一内部安排执行，三条路线的范围和金额相同，金额U暂未取得 | 相等关系有依据；U仍未知，不允许按零计 |

尚未确认合批时，先算“每次交付各有一处理批”的条件情景，同时问清是否必须这样安排。本情景的表面服务费为 `max(6×8,300)+max(24×8,300)=600`，运输为120。它不是未经确认的确定订单费用，也不是所有可能分批方式的上限。

| 完整配置 | 计算式（未含共同未知U） | 条件小计范围 |
| --- | --- | --- |
| 通用装夹，两批处理 | 450+30×20+30×[50,58]+600+120 | 3,270–3,510 |
| 快换装夹，两批处理 | 950+30×20+30×[35,42]+600+120 | 3,320–3,530 |
| 整件外协，两次运输 | 30×110+120 | 3,420 |

此时经济范围重叠，不能宣布自制一定便宜。不能把通用装夹450与快换重复成本35拼起来报2,820；这不是已提出的一套配置。也不能将外协整件价再加一次自制材料和表面服务。

本轮有价值的下一问是：“最低收费按什么批算？可否30件一起处理，分6件和24件送回，仍满足原定交期、储存和追溯要求？”不必重问已有来源明确的税口径和整件报价包含项。

## 第二轮：只揭示一项新答复

S-T2：供方确认本版30件在容量和工艺相容范围内，可在首批到期前齐套处理成一批，再按6件和24件配送；约定储存、追溯和两次运输均满足原交付要求。服务费按处理批收费，储存不加费。产品要求和交付日期未变。答复是计划条件与报价范围确认，尚未实际加工或放行。

本轮表面服务费变为 `max(30×8,300)=300`，运输仍为120。把处理批数从2改成1，其余参数不因这条答复而升级。

| 完整配置 | 更新后条件小计（仍须加U） | 相对整件外协的条件差额 |
| --- | --- | --- |
| 通用装夹，一批处理两次运输 | 2,970–3,210 | 少210–450 |
| 快换装夹，一批处理两次运输 | 3,020–3,230 | 少190–400 |
| 整件外协，两次运输 | 3,420 | 比较基准 |

两条内部路线的小计均下降300，原因是批次假设被答复收窄，单价8没有下降。最低收费没有制造额外零件：仍是30件，不是把300÷8当作新交付数量；也不能因为只有一处理批就只计一次运输。

在本例明列的范围内，两条内部路线有费用优势；实际能力、损耗和估算取值仍是条件。U在三条路线金额相同，所以可从差额消去；完整订单总成本、现金需求及对外报价仍未确定。不能把3,210或3,230称为完整成本上限。

两条内部路线之间，快换多投入500；只有通用方案每件重复成本比快换高出超过 `500÷30≈16.67`，快换才更便宜。当前估计中的差值可能小于或大于该数，两条内部路线尚不能唯一选定。这里没有样本概率，不能取各范围中点宣布“最可能节约”。

## 反馈怎样进入下一轮

- 工艺/采购交接更新为一处理批、两次配送，绑定S-T2；原S-T及第一轮假设保留。
- 卡5中把处理费600改成300，运输120保留，预算及路线比较同步更新；不登记为实际节约300。
- 技术下一步核配套装夹下的占用与质量条件。即使取得少量试件用时，也只更新匹配的工序和估算依据，不自动扩成整批上下界。
- U仍需落实以完成总预算，但已有相等依据使它不是本例三路线差额的首要未知。若后续包装或验收范围不同，相等关系失效，重新比较。

反例对照：仅知道“三家都有包装费”不够相消；若没有S-P，须分别保留未知额。仅知道设备可调配，也不够将S-J的时间范围标为已验证。
