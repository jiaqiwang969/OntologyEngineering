# 合成案例的审阅依据

本例原文是随源码公开的教学输入。它包含用户目标、一个明确标为待纠正的助手声称，以及后续纠正。它没有真实设备、采样结果或外部工具运行。

本次整理保留三个事件；纠正明确指向先前声称，原声称和来源均不删除。能够从这些原文整理出的经验是：有限离散观察的证据范围不能直接扩大为连续路径通过。这里记录的是讨论中提出的方法与纠正，不是对该方法有效性或物理系统安全的独立证明。

经验可以标为整理审阅完成，但必须保留“没有实际采样”“没有连续路径验证”“没有工程采用或收益证明”等未知。将经验登记进 Project 只增加候选来源，不形成决策支持或工程通过。

示例使用 `no_delta` 反馈：它确实把候选用于记录证据范围，但没有对照证明工程收益。回放验证的是公开安装能否保存、核验、回交、登记、反馈和再次召回同一条完整经验。回放本身不能替代新任务中 Agent 的语义审阅。
