- 原资料链接与文件身份：[source-delivery.json](../../runtime/source-delivery.json)

## 本次交付

0.7.0 将工程知识查询、来源接入和现有 CAD／制造／证据方法组织为可整体安装的软件分发。代码经 GitHub 与核心 ZIP 提供；大型原始资料通过 Drive 单独交付，下载目前需要相应访问权限，下载校验后归回 `~/.codex/skills/ontology-engineering/sources/`。

- 同一 `scripts/jev_knowledge.py` 入口查询已登记教材和 MISUMI，支持离线候选、Jev 判断、项目上下文、原页图片和证据包。
- `scripts/source_library.py` 按单一交付清单列出、导入、校验、显式下载和登记资料；默认目录覆盖书籍、供应商资料及索引。
- MISUMI 目录无损压缩保存原页，查询按需恢复并核对 SHA；完整目录 PDF 可显式恢复，不默认展开全部原件。
- 代码、来源、项目与运行状态保持同一安装根；`sources/` 与 `var/` 排除于 Git 和核心包。搬迁、来源身份与原页定位有明确入口。
- Jev 复用共享工程方法与既有五组模式问题，保留判断、未知与失败；独立章节批次有界并发，覆盖和预算记录可追溯。原页可通过 `--view-page` 直接打开渲染入口，不受结果排名限制。
- CAD 继续使用 NXOpen／Journal 直连；Semantica 继续是唯一正式语义执行器，没有新增平行语义后端。

使用命令和外部前提见 [README](../../README.md)、[English README](../../README.en.md) 与 [安装说明](../PORTABLE-DISTRIBUTION.md)。普通包不附账号凭据、NX 软件或许可。仅概念检索和阅读原页不需要 NX。

## 本次范围与后续验证

本次范围是完整的软件分发、安装和来源接入。软件单测、文件校验与合成场景检查只支持各自的软件结论；工程案例持续用于检验知识采用、设计实现和制造反馈。

已提供目录导航、文本索引、来源身份和候选交接；尚不能据此宣称六书已完成本体化，或资料能够自动形成正确机构与完整工艺。扫描正文、图表公式、用途匹配、适用条件、工程采用及变更影响仍需按具体问题核查。Jev 路由或检索完成不等于工程决定正确；CAD、计算、试验和正式语义审查各有边界。

后续以真实案例检验“来源原页 → 条件／机理 → 采用或拒绝 → 同版设计／工艺改变 → 验证反馈”，并据证据改善候选精度、上下文接续和跨章节关系。此次发布不包含实物能力、加工成本收益或生产放行的保证。

## English release summary

The 46 previous book-source digest mismatches are repaired in pinned Semantica 0.6.5+oe.7 after reviewing the retained source changes; all 238 source checks pass. Refinery verification reuses successful computations within one locked operation while continuing to hash every CAS read and rejecting tampering. This does not change chapter completeness or grant engineering release approval.

Software distribution for tag `manufacturing-v0.7.0`, with the core ZIP and build verification attached to the GitHub Release.

This version delivers an integrated, installable engineering skill: one knowledge entry point for registered textbooks and MISUMI, manifest-based source import and registration, lossless catalog storage with page-by-page restoration, and original-page access with source identity checks. Code is distributed through GitHub and the core ZIP. Sources downloaded with the required Drive access return to the same installation under `sources/`; private projects and runtime data live under `var/`. Both trees are excluded from Git and the core package.

Jev provides bounded candidate judgments using shared engineering methods. NXOpen/Journal remains the CAD execution path, and Semantica remains the sole formal semantic authority. Credentials, NX software and licenses are supplied by recipients. Conceptual queries and page reading can be used without CAD.

The release provides the complete software distribution, installation workflow and source access. Software tests, file checks and synthetic cases support their own software conclusions. Engineering cases continue to assess knowledge adoption, design implementation and manufacturing feedback. Chapter navigation and text indexing do not mean whole-book ontology modeling is complete. Relevance, applicability, engineering adoption, native CAD checks and physical validation remain distinct.

Original repository code retains its MIT license, and third-party components retain their notices. The four third-party textbooks, original supplier documents, private project files, credentials and caches are not published to GitHub or included in the core ZIP. Books and original supplier documents are delivered separately through the manifest’s Drive links; downloading currently requires the appropriate access. This software release does not make those documents public or change their publication status, copyright or redistribution terms.
