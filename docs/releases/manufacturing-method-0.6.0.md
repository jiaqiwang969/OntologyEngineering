# 工程本体 0.6.0：NX、米思米与经验复盘

本版本把 CAD 默认执行迁到 Siemens NX 的 NXOpen/Journal，供应商资料优先米思米中国；
保留机构学先行、接口、公差、装配、制造和证据方法。Fusion 应用、MCP 适配器和运行 wheel
退出当前执行及安装范围。历史教学文件只作方法与来源参考。

资料取得从当前用途出发，向 Jev 提供网页实际的模型格式、图纸、规格及采购资料选项。
先核指定会话与完整型号，保留派发结果不明时的状态，检查真实新文件，再分别做内容与
原生验收。新增可选 Jev Ultrafast 工具，源码和依赖固定；普通分发不含账号或凭据。

经验复盘现在从真实记录提炼候选，经 Jev 建议和主 agent 复核后进入对应操作指南；
下一任务按适用条件查阅正文，记录采用与验证反馈。它是任务检查点的方法，没有自动
启用夜间常驻调度；操作指导更新不等于正式行业本体晋升。本轮正式本体学习为 no_delta。

  已核归档与哈希；这不是十次无人值守冷启动通过，也未验证失效会话的密码恢复。

  10 项查阅回归符合预设参考。动作对照有无经验均为 7/7，未证明准确率或现场收益提升。
  这些参考由主 agent 编写，不是独立人类基准，也没有新增浏览器或原生 CAD 执行。
- 新文件取得、原生几何/单位、机械适用性和采购放行各自验收。Jev 的完成选择不关闭
  尚未取得证据的父目标；SolidWorks MCP 接入本轮未交付。
