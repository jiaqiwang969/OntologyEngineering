# 制造工艺与成本管理方法 0.5.3

本次提交把可复用的制造方法纳入整个 `ontology-engineering/` skill。由不完整的客户
询问出发，沿“要求与情境 → 对象和状态 → 工艺与检验 → 设备和供应商 → 费用与
证据 → 方案反馈”推进，持续发现隐性知识，并留下变更依据。

## 包含内容

- [制造模块入口](../../skills/manufacturing-process-cost/SKILL.md)：资料筛选、情境迁移、
  精度与工艺、设计到加工、自制外协、验证投入、变更适用和估算依据。
- 八类 JSON 记录模板、十二项判断方法和六张可选评审卡。
- A→B→C 演变的方法说明、四轮合成报告输入和五个后续决策练习。
- 原生 XeLaTeX 报告组件，以及顺序、并行汇合、检验返工、条件工序和资源成本关系
  五类 TikZ 工艺图模板；包含可读的五页图册。
- 锁定的 Semantica 制造案例传输包：141 项声明资产、68 个合成场景、23 个 CQ，
  配有完整性检查与原生案例执行入口。
- 分发工具、回归测试和[接收方验证步骤](../PORTABLE-DISTRIBUTION.md)。

方法版本为 `0.5.3`；记录模板为 `0.2.0`，评审卡为 `1.4.0`，报告与图形模板为
`1.0.0`，冻结语义包为 `0.1.1`。这些版本各有范围，不用文档更新冒充语义规则更新。

## 上传范围与使用边界

本次公开范围以[逐项资产清单](manufacturing-method-0.5.3.json)为准。它登记新增和
修改文件的摘要、来源方式、许可证及本次仓库所有者的上传授权；冻结语义包的每个
成员单独登记，并有[独立 NOTICE](../../runtime/vendor/MANUFACTURING-NOTICE.md)。
清单自身的完整性由所属 Git 提交保留，后续更新使用新的版本记录。

客户原件、企业或供应商身份、真实报价、具体模型、对话、私有项目映射和内部执行
日志不在上传范围。案例中的对象、参数和数字用于方法教学，不能当成客户事实。

这是制造方法的仓库更新。仓库原有的[两卷书整体发布状态](../PUBLIC-RELEASE-STATUS.md)
和书源绑定记录保持原状，不以本次授权宣称整个书包已清权；也未发布一个整体书包
下载附件。使用时仍取完整仓库根目录，模块的相对引用及运行时位于同一分发根目录。

合成案例回放与工具测试各有验证范围，不能替代新报告自身的工程语义核验、真实
设备能力、实际成本或制造放行。此次仅分发已有知识，语义学习结论为 `no_delta`，
冻结候选没有因上传而晋升。
