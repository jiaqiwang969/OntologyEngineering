# 对象、状态、能力与成本

## 最小关系图

下面是观察与记录用的概念映射，不是可执行本体声明。优先复用当前 Semantica 包已有的身份、来源、主张、需求、权限和依赖概念。

| 对象 | 必须分清的内容 | 连接到什么 |
| --- | --- | --- |
| 决定与情境 | 用途、装配、工况、失效后果、数量与交付 | 要求、旧经验迁移理由、当前可承诺范围 |
| 产品版本 | 图纸、模型、BOM、变更、报价对应证据 | 工艺输入、检验对象与成本基准 |
| 工艺状态转换 | 输入状态、操作、输出状态、前置条件 | 顺序、返工、资源与后续检验 |
| 检验计划/结果 | 阶段、特性、方法、判据、受检状态 | 要求覆盖、测量记录与结果失效条件 |
| 能力判断 | 设备、工装、人员、材料、程序与条件 | 可调配、可安装、可加工、已验证质量及节拍 |
| 供应/交接范围 | 谁完成到哪一步、验收、运输与责任 | 自制外协边界、费用归属和交期 |
| 成本情景 | 数量单位、版本、范围、含税状态、假设 | 工序、资源、供方报价与预算/承诺 |
| 知识缺口/发现 | 为什么重要、已查内容、关闭条件 | 问题、答复、验证和决定变化 |
| 方案/输出版本 | 源快照、生成依据、读者、成熟度 | 反馈、替代关系与自身验证范围 |

同一结论保存独立维度：内容清晰度（未知/部分/明确/冲突）、依据类型（声明/观察/推断/估算/计算/测量）、解释是否核对、谁认可了什么范围、当前适用性及适用对象。客户确认不会把估算变成测量，技术通过不会把建议变成订单承诺。

几何特征、功能特征与加工操作分别关联；设计模型、中间材料状态、工艺计划与真实执行分别记录。顺序变化可能改变基准、承载与可达性，并通过装夹、刀路、检验和资源投入影响费用。按[因果联系](requirements-process-cost.md)和[STEP 加工链](step-to-process.md)将这些条件展开，不能仅按操作名排序。

## 情境迁移与制造顺序

将每项既有控制关联到它防止的失效或满足的要求，再比较新情境。迁移结果可以是保留、修改、新增、拟取消或待定；后两者须留下依据与验证/采用条件。不要仅凭行业名称决定公差、清洁度、检测比例或设备等级。

用“输入状态 → 操作 → 输出状态”表达路线，另列检验覆盖。处理前检验与处理后检验可以针对不同性质；顺序取决于要求和操作影响。后续操作若改变已检性质，复核原结果的适用性和补检需要，不能简单套用“全部检完再处理”或“所有检测都放末尾”。

设备表只能支持它记录的身份、配置和状态。能力判断还可能需要加工范围、夹持可达性、材料与工艺窗口、测量覆盖、试件和重复性等证据。验证取决于本轮决定，不要求每项普通加工都重做全部试验。

## 比价与成本核算

先建立共同比较范围：产品/版本、各型号良品数量、交付边界、质量要求、交期、费用币种与税口径。将来源报价、内部预算、完整资源成本、现金支出和对外价格分别记录。税率依来源记录，不能默认一个地区或行业税率。

| 费用维度 | 容易遗漏或重计的地方 |
| --- | --- |
| 一次性 | 设计、编程、工装、调试、验证；按订单/型号/共享资源分别归属 |
| 按批 | 换线、装夹准备、检验设置、物流；不要又并入单件工时 |
| 按件 | 材料、运行、人时、耗材、检验、后处理；确认报价是否已含 |
| 损失与间接 | 返工、报废、维护和管理分摊；避免在良率和单价里重复加入 |
| 现有资产 | 新增现金可能少，但运行、维护与人时仍需计；资源成本与现金口径单列 |
| AI 辅助 | 设计、编程、复核、联调、试机、维护及工具费分开；节约先作为情景 |

在口径明确且不重复计费时，可用：

`订单成本 = 一次性费用 + 各批费用 + 各型号数量 × 对应可比单件成本 + 尚未包含的其他费用`。

参数来源、计费批次和条件范围按[估算依据](estimate-basis.md)展开：处理批、运输批和交付批不一定相同；共同未知费用只有在金额相等有依据时，才可从路线差额消去。

若单价已含一次性分摊，不能再全额相加。未知项保留未知，输出“已知小计 + 待核项”或有依据的范围，避免伪装成完整总价。良率影响应进入实际损耗、返工或数量模型，不能一律对所有成本除以良率。

**合成教学算例（任意成本单位，不是项目报价）：** 同一版本、同一验收范围的单型号加工件，需要一次性准备 1,200，每件重复成本 75；外协每件 110，不另收费。数量 40 时，自制为 4,200，与外协 4,400 可比差额 200；数量 80 时，自制为 7,200，与外协 8,800 差额 1,600。这里只有准备费和重复费，只有在其他费用已同范围处理、设备能力成立时，差额才支持该情景的经济比较。未计项目必须显式列出，不能将这段示例作为接单价格。

先查真正可变的成本驱动：是否误搬不适用的控制、能否复用工装/程序、是否重复采购或检验、换线/装夹/等待在哪里、设计是否便于制造、AI 减少的人时是否被复核或试机抵消。把每个降本想法接到受影响要求、费用项、验证办法和实施代价，不先承诺节约比例。

比较单型号改选时，用 [P09—P11 的预算变化、可避免费用与敏感性方法](decision-patterns.md)。分摊给该型号的共同投入不一定随外协消失；启动前与已开工后要分别核算。制造、处理和检验批次如何连接产品及成本实绩，见同文 P07。
