# Book Roadmap and Learning Paths

# ==============================
# 1. 全书结构
# ==============================
#
# 第1章 绪论
#   └── 哲学本体论 → 工程本体论的转向；AI时代定位
#
# 第2章 本体论基础理论          ←—— 理论地基
#   └── 类/属性/公理/实例；描述逻辑；一阶逻辑；单调与非单调推理
#
# 第3章 本体构建方法论          ←—— 怎么设计
#   └── 能力问题(CQ)；Ontology 101；METHONTOLOGY；OntoClean评估
#
# 第4章 本体描述语言与工具      ←—— 怎么表达
#   └── RDF/RDFS/OWL；SPARQL；Protégé
#
# 第5章 知识表示与推理机制      ←—— 怎么推理
#   └── Tableau算法；SWRL规则；时态推理；概率推理
#
# 第6章 工程领域应用案例        ←—— 用在哪里
#   └── 制造调度；自动驾驶；BIM；航空FMEA
#
# 第7章 知识图谱构建与管理      ←—— 怎么规模化
#   └── 抽取/对齐/融合；存储选型；SHACL质量校验
#
# 第8章 本体与大语言模型        ←—— 怎么与AI融合
#   └── 幻觉控制；GraphRAG；Text2SPARQL；本体引导Agent
#
# 第9章 综合实战案例            ←—— 全栈落地
#   └── 智能制造知识管理系统（OWL + Jena + owlready2）
