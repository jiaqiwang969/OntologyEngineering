## 二、超出 X1 的方法增量（全部经审计验证）

1. **台架场景语义（模块化装配的正解）**：官方指南"分组并行制作"⇒ 子装配在台架上
   组装时其他单元不在场。工序加 predecessors DAG；行走/审计在场集=本工序动件+前驱
   闭包动件。旧口径（全部更早件按最终位姿在场）造成 35 例假卡死（脊柱被电机单元
   卡死等），台架化后降为 8 例真卡死。**成片可见性同语义**：台架章只显示本台架，
   装完隐藏（"放一边"），结合章按闭包重现——否则动件飞入会穿过画面上可见的其他
   台架（v002 审计实测 39 例）。
2. **presence-only 结合章**：unit-join 章 movers=[]，只做前驱产物汇合呈现+诚实
   HOLD 标注（"结合运动未认证，不主张结合动作"），相机取闭包并集。
3. **卡死件章末出现**：not_animated 的静态呈现放在本章全部动件就位之后
   （章首出现会被随后的支架/盖板动件穿过——6/8 例穿模由此修复）；且不得走
   context 通道提前出场（审计与画面口径必须一致）。
4. **宽松平面图作轴候选源**：舵机侧向放进开口卡槽的方向是 0.05–0.5mm 间隙贴合，
   默认 gap=0.05 的平面图看不见 ⇒ 单独生成 gap=0.5 图仅供行走取轴（S8 边仍用默认
   阈值，宽松对以 PLANE_LOOSE 分级入图消除"无入边却在动"告警）。方向候选不需要
   认证配合——行走本身就是测量裁决。
5. **S5 求解单元折叠（Fourier 规模必需）**：执行器整装/轴承（含滚珠建模）/PCBA
   （电子件占比>=0.6 且叶>=5 的子树）/电池包 ⇒ 按 SOP 整体安装语义折为单元
   （1 mover，成员逐一列账满足 A4）。折叠根自顶向下先到先得，不嵌套。
6. **坐标语义实测，不猜**：200mm 网格连通聚类找主簇（隔离源 CAD 游离/停放件），
   命名锚点（肘关节-L/-R、foot/head 关键词）定侧向轴与符号；up 轴配置驱动
   （T-pose 人形的"最大跨度轴"启发式会选到臂展轴）。左右分侧后须对称性自检。
7. **审计→可播表回灌**：film 审计 PENETRATES 的动件按 TRIMMED_TO_FIRST_NON_BASELINE
   收短；仅被"卡死件"挡住的不收短（其已改章末出现，飞行期间不在画面）。
8. **A9 全量回读**：独立进程重开 .blend，逐动件核 f0/f1 位置（X1 只抽 3 样本）。
9. **X1 面板时钟缺陷修复**：右栏边 realized 帧消费 context_deferred_fasteners 与
   static_withdrawn_appear_frame 的真实出现帧。
10. **验证器前置**：MP4 生成前必须 `validate_acceptance.py --profile engineering-film`
    全机器门 PASS（人工门除外）；渲完再撤的旧循环禁止。

## 三、判据陷阱台账（新增实证）

- THICK_END 粗端判据分域验证在 Poppy 全类不成立（10 个 GEOMETRY_FORCED 样本 0 吻合）
  ——不同装配必须重验，不吻合一律降级 UNDETERMINED，方向交由直接量+行走。
- SolidWorks 配置陷阱：产品名可为"文件名_配置名"双件号拼接（GB-T70-1-M3X12…_M4X8…），
  实际尺寸须由 S2 圆柱几何裁决。
- 名称编码三层：源字节编码（gb18030/cp850 需证据裁定）+ ISO-10303 \X2\UTF-16BE 转义
  + OCCT 丢 0x82 类字节（XCAF 名须 ASCII 归一匹配）。
- 一个子装配可含双侧（Fourier 下肢大腿单元 Y 跨 ±319 同含左右腿）——分侧要在
  单元内按侧向轴中线切，不能按单元质心。
- FCL 与 BVH 在零距离贴合处语义不同（FCL 判碰撞、零容差 BVH 不判）——交叉验证的
  approach 差异集中于此，属已知分歧非实现错误。

## 四、Windows/SolidWorks 无人转换剧本（dell-nb 实战）

前提：目标机 SSH 用户=控制台登录用户。SolidWorks 只向下兼容——**先探文件版本
再定安装版本**（OpenDoc6 errs=8192=swFutureVersion 即版本不够）。
1. GUI 自动化必须落在交互会话：`schtasks /create /it`（SSH 会话 0 无桌面，Rhino/SW
   首启对话框永远没人点）。任务与目标进程必须**同完整性级别**（UAC ROT 隔离双向断）。
2. 该机 PowerShell COM 晚绑定/Interop 转换可能整体损坏 ⇒ **纯反射
   `[Type]::GetTypeFromProgID + InvokeMember` 或 VB `Interaction.CallByName`** 全通。
   多版本并存用带版本 ProgID（SldWorks.Application.33=2025）。
3. ps1 必须带 UTF-8 BOM（无 BOM 按 GBK 读，中文路径变乱码→假"文件未找到"）；
   函数内诊断一律 Write-Host（裸表达式会污染返回值成 Object[]）；
   OpenDoc6 ref 参数用 ParameterModifier 且返回值需解包。
4. COM 拉起的 SLDWORKS 首启会卡死无窗口 ⇒ 让用户 GUI 开一次（含缺件"压缩所有
   缺失零部件"人工裁定），脚本附着 ActiveDoc 只做 SaveAs3 导出。
5. 顶层判定别信文件名尺寸：Robben(215MB)=头+躯干模块，真整机是"总装模型"命名
   （用户目视+叶数闭合双确认）。缺失引用被压缩的件不在 STEP 内，凭 Ebom 对账入台账。
