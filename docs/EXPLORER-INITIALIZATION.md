# Explorer 初始化与来源

七个现有 HTTP 适配入口在监听与报告 ready 前，沿唯一 DatasetSession 建立派生搜索索引，然后重新核对原图文件身份。索引不建立新的 Project、来源权限、查询预算或经验账本；搜索继续使用这一缓存。

`--duration-ms` 覆盖本轮资料读取、初始化和服务循环，初始化消耗相同截止时间，不在 ready 后重置。已有数据集和派生缓存的逻辑字节上限保留，不能解释为进程 RSS 上限。

原 GraphSession 构造先转换 confidence，再处理 tags。超大整数转换失败及非空不可迭代 tags 在启动时拒绝；空值、字符串及可迭代对象按原逻辑处理。多个错误保持原发现顺序。更新原图使旧缓存失效，失败初始化不发布新缓存或改变图。

工程本体规定数据、来源与错误含义；这些约束由 specs 经真实 ggen 生成验证映射，Rust 复用原 owner 执行。本轮是迁移行为修复；RRSI 的工程改进收益和采用须继续沿原经验链取证。42 组原输入用于已见回归，不代表所有数据形态、完整 Server/UI 或存储后端已迁移。

启动拒绝保留明确错误码：整数转换溢出、tags 不可迭代、截止时间及索引资源不足分别报告；未知底层错误继续使用原通用错误，不外泄原值或路径。
