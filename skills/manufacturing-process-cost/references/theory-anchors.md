# 方法来自哪里

两卷书指导观察和建模；项目原件与现场记录支持工程事实。本模块不把书中的教学材料当行业标准，也不把实例变成所有制造企业的默认要求。

路径相对于本文件，指向同一 skill 内的受控书源。按问题读取相关部分，无须每次读全书。

| 当前问题 | 书源与定位 | 用在制造工作中的方式 |
| --- | --- | --- |
| 怎样问出隐含条件 | [第一卷第 3 章](../../../references/ontology-engineering-book/handbook/chapters/ch03.tex)，检索“从专家访谈中提炼能力问题” | 从原话取得条件、例子、分歧和可检验问题 |
| AI 怎样辅助知识获取 | [第一卷第 8 章](../../../references/ontology-engineering-book/handbook/chapters/ch08.tex)，检索“知识获取” | 协助提取和组织，保留来源及专家核对 |
| 未知与证据能说明多少 | [第二卷第 11 章](../../../references/product-trustworthiness-book/ch11-claim-ontology/chapter.md) | 不把缺项当否定；局部资料完整不等于真实工艺通过 |
| 图纸、模型、报价对应 | [第二卷第 12 章](../../../references/product-trustworthiness-book/ch12-identity-ontology/chapter.md) | 对象身份与版本关系分别建立 |
| 谁承办、复核、决定和采用 | [第二卷第 13 章](../../../references/product-trustworthiness-book/ch13-governance-ontology/chapter.md) | 角色绑定具体活动、权限、对象版本与有效范围 |
| 旧经验能否迁移 | [第二卷第 14 章](../../../references/product-trustworthiness-book/ch14-context-hazard-ontology/chapter.md) | 记录情境和判断理由，变化后重开适用性 |
| 要求怎样驱动工艺 | [第二卷第 15 章](../../../references/product-trustworthiness-book/ch15-requirements-ontology/chapter.md) | 追踪要求、派生理由与实现措施 |
| 检验结果何时适用 | [第二卷第 16 章](../../../references/product-trustworthiness-book/ch16-measurement-ontology/chapter.md) | 测量结果绑定对象、方法、条件及判据 |
| 为什么新版本不同 | [第二卷第 17 章](../../../references/product-trustworthiness-book/ch17-change-ontology/chapter.md) | 保留旧快照和改变依据，不覆盖历史解释 |
| 改一处需要重查哪里 | [第二卷第 18 章](../../../references/product-trustworthiness-book/ch18-dependency-ontology/chapter.md) | 跟踪受影响工艺、资源、成本和输出，暴露依赖缺口 |
| 现场结果怎样返回方案 | [第二卷第 19 章](../../../references/product-trustworthiness-book/ch19-field-ontology/chapter.md) | 区分设计、批次与单件，追加观察和事件，不把预算当现场实绩 |

案例将上述方法用于制造决策，是领域应用设计；是否成为正式通用语义由根 skill 的验证与采用流程决定。
